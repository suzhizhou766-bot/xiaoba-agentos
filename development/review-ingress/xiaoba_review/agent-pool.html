名称、调用方式、入口和模型均由你指定，也可通过与小八对话补齐。新节点先关闭；开启并测试通过后，小八直接使用适用节点，不重复问这些资料。AGY CLI 使用脚本＋持续交互 PTY，可在节点内查看只读终端；其他 CLI、桌面或 Web 需要对应受信调用器。
