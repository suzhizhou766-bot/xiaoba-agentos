# 备用身份已退役

2026-11-02 起，小八没有默认审查节点，也没有专门的备用身份。谁审查、谁协作，只由用户在 Agent 池里设定。角色是审查、协作、两者。用户想要一个节点既能干活又能审查，把角色设成“两者”。

本轮或上轮干过活的节点，这一轮不派审查。身份任务卡改派给其它已开启、可审查的节点。还不够时，可以加上符合条件的宿主：宿主这次没干活、不是作者，而且不能两票都是宿主。全部审查员不可用时停下问用户；用户选了宿主兜底，才由宿主审查，并标明“无独立审查”。

旧配置里的线路名字和历史事件（包括 `standby.substituted`）仍能读。它们不参与新的派活，也不再作为发版门禁的合格组合。

以前的补位判断表是 v1.6.5 的历史规则，留在 `docs/RELEASE_V1.6.5.md`，不在这里继续生效。
