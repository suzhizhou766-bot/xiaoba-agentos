# 裁决弹窗验证记录（2026-10-05）

本次在现行「核对 → 处理中 → 结果」方案上修复进度与重试逻辑，未调整布局、处理期间的关闭限制，也未改 AgentOS 裁决后端。

## 修复

- 审核记录按候选、阶段、决定、完整证据哈希匹配，并排除提交前已有的回执编号，不再依赖客户端时间窗口。
- 全局同步时间变化不再作为本批次发布、索引校验或同步成功的依据；这些步骤由完整正式回执确认。
- 轮询一次只保留一个在途请求，迟到响应不能覆盖结果页或下一次重试。
- 丢失或不完整的回执保留原提交编号与内容。候选从待审队列消失、关闭弹窗或刷新状态失败后，仍可通过原「预览综合裁决」入口恢复核对，并按同编号重试。
- 尚未取得完整回执时，不能用新裁决清单覆盖该提交。完整业务失败回执会显示失败原因；同编号重放不是重新执行失败操作。
- `recovered`、业务失败、发布结果未确认、同步失败不会显示「全部处理完成」或声称正式索引验证成功。
