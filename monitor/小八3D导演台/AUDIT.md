# 0.8 空间校准、越界穿帮、落地支撑与提示词可用性增量验收

日期：2026-09-16。本轮全面攻坚交接提出的四大核心技术痛点：

- **自动化测试**：`npm test` 24/24 项行为与空间回归测试全部通过；`npm run build` 1.77s 零报错通过。
- **图片空间校准**：`SceneBoard` 扩展 `pitch` 俯仰与 `horizonRatio` 地平线比率（0–100%），新增「底边贴地」与「地平线对齐机位」一键计算，使背景板世界地平面与虚拟摄影机视线无缝对齐。
- **背景越界处理**：`boardCoverage` 实现 `overflow: {left, right, top, bottom}` 四向精准诊断；监看视口实时渲染方向性穿帮边缘 HUD 与越界告警；时间轴 Tracks 直接渲染条状斑马纹越界区间警示带。
- **人物落地关系**：`groundedPositionY` 基于世界包围盒底面计算精确接触高度，点击地面或任意道具（桌子/台阶/箱子）表面均可让角色脚底精准站立，并在对象属性提供「脚底贴齐地面 (Y=0)」快捷按钮。
- **提示词可用性**：新增 `macroCameraMovement` 宏观运镜总结与主体构图演变提炼；输出 Seedance 2.5 / Gemini Omni 1.1 Flash 格式的纯净投递提示词（带槽位绑定与物理透视不变量），编译器提供「一键复制纯净提示词」按钮，与审计诊断报告彻底隔离。

## 明确的 MVP 边界

- 没有视频生成 API；交接包由用户提交助手，助手制作最终图片和模型提示词。白模预演 PNG 不是最终 AI 图。
- 景深为生成意图参数，监看没有光学散景；界面已明确标注。
- 关闭/刷新前需要保存项目，无跨刷新自动恢复。已支持会话内完整 50 级「后退一步（撤销 ⌘Z）」与「前进一步（重做 ⌘⇧Z / ⌘Y）」。
- GLTF 压缩解码器未配置，大型场景与复杂贴图未做广泛兼容性验证。
- Web 可独立在普通桌面浏览器使用；Tauri 仅预留结构，未交付签名桌面应用。
