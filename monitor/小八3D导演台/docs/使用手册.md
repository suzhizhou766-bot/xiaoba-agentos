# 小八 3D 导演台使用手册

在浏览器里搭一个三维舞台：摆人和道具，架摄影机，排出运动，导出图片和交给 AI 助手的资料包。全程在本机完成，不联网。

## 打开

打开小八监看中心，点「3D 导演台」标签（http://127.0.0.1:8799/#stage），跟着监看中心一起开关。浏览器要支持三维显示，窗口建议 1440×960，最少 1040 像素宽。

（依据：README「启动」）

## 第一次打开做什么

1. 点「打开」，选 examples 文件夹里的 demo.xbdirector.json，载入双人示例。
2. 空格播放暂停，拖动时间轴尺定位。
3. 左边是场景列表和添加按钮，中间是自由观察画面，右上是监看（最终画面），下面是时间轴。
4. 左键环绕，右键平移，滚轮缩放。

（依据：README「五分钟上手」）

## 摆角色和道具

- 左侧选角色，也可新增角色和方块道具。
- 「对象属性」改位置、旋转、缩放；或按 W 移动、E 旋转、R 缩放，R 拖 X 手柄是等比缩放。
- 自己的模型：文件拖进来，或一次选中模型本体和它的贴图、伴生文件；不能拖文件夹。按米算，保留原比例放到地面；自带动作不播放，只显示默认姿势。
- 站稳：对象属性点「脚底贴齐地面 (Y=0)」，或点桌子、台阶这类道具的表面。
- 锁定后什么都改不了，也删不掉。

（依据：README「素材导入约定」）

## 摆摄影机和选景别

- 选中角色，点右侧「摄影机」页签，选 ECU / CU / MCU / MS / MWS / FS / LS / ELS 之一，按人的外框算好距离和构图。
- 手动架位：左侧选中摄影机，W 拖机位、E 转向（同时改视线方向和滚转）。
- 切「主相机视角」就和监看同一台摄影机，点「操控机位」后左键环绕、右键平移、滚轮推拉。
- 焦距、机位高度、滚转、光圈都能调，但监看不会真的虚化。景别认不出脸和关节，非人物模型要微调。

（依据：README「五分钟上手」「时间轴与摄影约定」）

## 打关键帧做运动

1. 第 0 秒调好机位、视线、焦距，点「打关键帧」；拖到另一秒改完再打一次。
2. 相机记下全部摄影参数；角色记位置，旋转缩放也能记。
3. 点轨道名右侧菱形同样记录，右键删除，单击跳过去；同一对象同一秒再打会覆盖。可勾「自动打帧」。
4. 每秒 24 帧。第一个键之前保持第一键，最后一个之后保持最后键；没打键的对象停在当前姿势；缩短时长会删掉超范围的键。
5. 「后退一步」⌘Z、「前进一步」⌘⇧Z，最多 50 步。
6. 运动曲线：时间轴工具栏下拉框，可选匀速、缓入（起步慢）、缓出（收尾慢）、缓入缓出，不设就是匀速。曲线设在哪一秒的键上，就管它到下一个键这一段；整条镜头统一用「全部应用」。先把时间定位到一个关键帧上，否则下拉框是灰的。

（依据：README「时间轴与摄影约定」；AUDIT「0.4 功能验收」）

## 放背景图并校准

1. 「添加场景图片」选 JPG 或 PNG，每张不超过 20MB、最长边 8192 像素；刚放进来只是参考图。
2. 用途改成「空间背景板」才变成有边界的板子。调中心位置、宽高、朝向、俯仰角、地平线比率；留原图比例就宽高同比。
3. 点「摄影机正对背景板」取初始取景；它会真的移动摄影机，开着自动打帧会写进当前这一帧。
4. 地平线对不齐：「底边贴地」让图片下边落在舞台地面，或「地平线对齐机位」与相机高度齐平。
5. 背景不够会提示越界：画面四边出现半透明穿帮标记，时间轴出现斜纹越界段。板不会自己扩大，板内仍是平面图，没拍到的部分补不出来。
6. 调完勾「我已校准此简化空间」，只表示你确认过，不代表真实尺寸；改板参数会重回待校准。

（依据：README「图片与三维片场（0.6）」「0.8 空间校准、越界穿帮、落地支撑与提示词可用性」）

## 导出首尾帧

设好首尾帧，点「预演首尾帧」得到两张图；点监看右下方图片按钮只存当前帧。图片固定 1920×1080，辅助线不进图。这些是白模预演图，只控制构图，不是最终画面。

（依据：README「五分钟上手」；AUDIT「明确的 MVP 边界」）

## 用导演编译器导出交接包

1. 打开「导演编译器」，先给镜头选模型：Gemini Omni 1.1 Flash 或 Seedance 2.5。没选时导出按钮按不动；旧项目第一次也要选。选择跟着镜头保存。
2. 压缩包含交接说明、项目文件、首尾图和中间三张图、场景原图、空间与运动记录、模型指南、提示词草稿。
3. 可展开「提示词教学与使用方法」，能单独下载；「一键复制纯净提示词」给出可直接交给模型的那份，和诊断报告分开。
4. 把包或提示词发给助手，助手结合角色、场景、风格参考做最终首尾图和提示词，再去视频平台生成。导演台不直接连视频模型。
5. 长度默认到最后一个有效关键帧，3 秒动作不会被补成 8 秒；要静止停留就手动选首尾范围或末尾加保持键。平台不支持所选时长时给分段方案。

（依据：README「当前制作流程（0.6）」「0.7 导出一致性修复」）

## 保存和找回工程

- 「保存项目」下载一个以 .xbdirector.json 结尾的文件，含所有镜头、参数、关键帧和模型本身。项目名、镜头名可改。
- 「打开」这个文件接着做；有问题的文件会拒绝加载并提示。
- 编辑时自动在本机存草稿，意外刷新或关闭后能自动恢复；离开前再点一次「保存项目」更稳。
- 镜头条点「＋」复制成新镜头，各镜头独立修改。

（依据：README「五分钟上手」）

## 常见问题

- 画面不显示或界面排不下：换支持三维显示的桌面浏览器，把窗口拉宽。
- 运动曲线是灰的：时间没落在有关键帧的那一秒。
- 导出时人物忽然变大：导出默认锁住对象第一个尺寸键，免得为补远近做的缩放变成身体膨胀；要大小变化得明确勾选允许尺寸动画。
- 想删对象删不掉：先看是不是被锁定。
- 压缩过的模型加载不出来：先转成普通模型文件再导入。

（依据：README「素材导入约定」「0.7 导出一致性修复」；AUDIT「0.4 功能验收」）

5. 「当前制作流程（0.6）」带 0.6，文档已写到 0.8，不确定是否仍最新。
