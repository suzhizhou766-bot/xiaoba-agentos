# 门户与实际本机模块的主题衔接（待审经验）

日期：2026-10-13。作者：Codex。记录性质：问题、修复与可复用流程建议；未经用户审核，不作为已采用的长期规则。

## 用户指出的问题与根因

用户指出首页与二级页面割裂，明确“二级页面”指点击模块后打开的本机监看中心。此前两次只改了门户内部的分区，未先沿链接检查实际目标。门户与本机页面及内嵌工具分别定义样式，门户的改动不会自动传递到本机页面。

## 本次修复

以已完成的红黑液态玻璃门户为视觉基准，补齐本机运行总览、裁决中心、Key 池以及内嵌导演台、3D 导演台的样式。樱桃红 #ED3321、炭黑 #121212 与灰白反光用于界面；状态语义颜色和 3D 场景内容保留其原有含义。增加返回门户的入口。

实际改动：xiaoba-monitor.html 的样式与导航；director.html 的样式；小八3D导演台/src/glass.css 的样式及其构建产物。

## 已验证的证据

- 样式稿先经浏览器查看；实际五个模块逐个打开核对。
- 两份 HTML 原有脚本的哈希逐项一致。
- 3D 入口 main.tsx、HTTP 门禁 web.py、监看入口 xiaoba_monitor.py 的哈希与修改前一致。
- 3D 项目构建通过；实际加载后的控件使用共享主色。
- 本机健康接口的七个模块均为 ok，跨站读取健康接口仍返回 403。
- 真正点击托管门户中的“进入运行总览”，到达 http://127.0.0.1:8799/#overview；主色为 #ED3321、底色为 #121212。
- 点击“返回工作台”实际返回原私有门户。

未执行裁决、启停节点、查询余额、生成媒体等业务写操作。技术检查与用户对创意的最终采用分别判断。

## 建议的复用规则（待审）

涉及“首页、二级页面、子页面”时，先明确所指的真实目标，沿用户的实际点击路径查看；分别检查本页、不同源页面和内嵌应用。统一主题的验收应覆盖进入与返回，不能用门户内部锚点、静态样式稿或单页截图代替真正跳转后的核验。
