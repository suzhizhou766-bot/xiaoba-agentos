# QC report schema

## Required sections

1. Scope and scan time
2. Deliverable candidates
3. Original/optimized text protection
4. Technical checks
5. Structural and creative checks
6. Version differences and unresolved items
7. Reusable assets to index
8. Final status: `PASS`, `PASS WITH WARNINGS`, or `FAIL`

## Severity

- `BLOCKER`: cannot deliver or risks using the wrong source/master.
- `WARNING`: deliverable is usable but needs a decision or cleanup.
- `NOTE`: improvement or future indexing opportunity.
