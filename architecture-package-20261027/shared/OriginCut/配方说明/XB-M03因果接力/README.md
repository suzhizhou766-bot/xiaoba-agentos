## 表达与依据

同一对象先按原速度移动 → 回到同一起点 → 只改变速度 → 相同观察时长下显示新位移 → 保留原位置参照 → 同一对象移到下一段参照位。

采用明确标注的匀速数学模型，依据 `位移=速度×时间`，不是对实拍或训练表现的因果分析。默认100示意px/s、2秒，得到200示意px；速度变成200示意px/s，同样2秒得到400示意px。模型显示比例为3设计像素/示意px，横轴不冒充真实空间标尺。

替代示例：80×2=160；速度乘1.5后120×2=240。它们是本地可计算关系，不需要借用未经核实的真实题材结论。

## 文件、参数和时间

- 源码：`components/xb-m03-causal-relay/src/main.js`，辅助绘制与字体：同目录 `design.js`。
- 参数唯一来源：该组件 `component.json#/propsSchema`。可调标题、强调色、原速度、速度倍率、是否保留原位置参照。
- 两组示例：`examples/default.json`、`examples/alternate.json`。
- 0–2秒建立条件；2–4秒原速度运行；4.7秒改变速度；5.35–5.95秒回到起点；6–8秒新速度运行；8秒后显示结果；9.5–10.7秒同一对象移作下一段参照；12秒结束。
- 四个轻提示音在1.92、4.62、5.92、9.42秒，增益0.35，音源同步点为源内0.08秒。
