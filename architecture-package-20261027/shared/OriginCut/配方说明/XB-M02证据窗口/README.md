## 看什么

提出观察问题 → 给出完整来源 → 标出支持区域 → 先留阅读时间 → 显示有边界的观察结论 → 来源缩成注记 → 结论归位。

与M01的区别：M01把局部展开成观察卡，再返回原片；M02着重呈现“结论从哪里来”，在来源获得阅读时间后才显示结论，最后保留可回看的来源标识。

## 时间与声音

| 时间（秒，终点不包含） | 动作 |
|---|---|
| 0–1.1 | 先给问题 |
| 1.1–2.3 | 完整来源进入左侧，问题转入右栏 |
| 2.55–3.2 | 支持区域标注出现 |
| 3.2–6.2 | 默认阅读停留3秒，暂不显示结论 |
| 6.2–6.9 | 本帧观察及限定语出现 |
| 6.9–9.1 | 结论与来源共同保留供对照 |
| 9.1–10.25 | 来源缩为左下角注记，结论保持右侧 |
| 10.25–11.05 | 来源已落定，结论再移到左侧 |
| 11.05–12 | 保留观察、限定语、完整来源缩图和时间码 |

阅读时长可调2.8–3.6秒；结论出现时间为 `3.2 + readSeconds`。总长固定12秒，后面的对照停留随之变化。调长阅读时长时，需同步移动结论提示音到 `3.2 + readSeconds - 0.08`。

复用本项目独立合成的 `audio-components/xb-m01-soft-handoff/src/main.ts`，两种参数对应两个已登记音频Asset。展开提示落位1.02秒、增益0.45；观察落定提示默认6.12秒、增益0.30。两者源内同步标记均为0.08秒。声音独立分轨，可分别移动和调整。
