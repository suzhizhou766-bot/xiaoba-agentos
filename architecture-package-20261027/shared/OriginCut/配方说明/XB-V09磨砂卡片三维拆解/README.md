# XB-V09｜磨砂卡片三维拆解

根据用户提供的第二份 HTML 制作的独立本地组件：三层暗色磨砂卡片、蓝色描边、白到蓝的渐变标题，中层7根示意波形。三维倾斜时文字和轮廓使用同一套空间投影，不再把字平贴在屏幕上。

预览：[20秒双视图](origincut://v1/sequence/seq_eh7bdj8nemn2ra?revision=3)。0–10秒为完整展开与重组；10–20秒隐藏前景，查看中层波形。原来的V01～V08和64秒总览保留。

## 使用与参数

项目本地组件列表搜索 `XB-V09` 或 `xb-v09-frosted-explode`。

- `title` / `subtitle`：标题及说明；参考默认标题为“Claude Opus 5.5”，只是参考文案。
- `layerLabels`：三层标签，默认 bg.layer / timeline.data / focus.ui。
- `mode`：cycle自动展开重组，open保持展开，closed保持合拢；源时长均为10秒。
- `angleY` / `angleX`：默认-28° / 14°，对应参考视角。
- `depthScale`：前后层距倍率，默认1；后层-80px、前层+90px按参考的2倍设计坐标换算。
- `frostBlur`：默认12，按参考CSS像素解释；0关闭内部磨砂采样。
- `waveSpeed`：7根示意波形的律动速度，不分析真实音频。
- `frontEnabled=false`：隐藏前景标题层，检视中层；适合检查或作为无标题版本。
- `backgroundEnabled=false`：透明输出；`showStageLabel=false`同时去掉下方状态字。
- `accent`、`backgroundColor`、`gridEnabled`：描边/标题渐变的强调色、背景色、点阵开关。

完整参数范围、静态示例及放置模板见 [recipe.json](recipe.json)。

## 实现与边界

点阵背景忠实保留为平铺32px网格（2倍设计下间距64），原HTML未给背景施加透视变换；三维关系来自卡片的共享空间矩阵和透视相机。

图层轮廓、标签、标题与波形共用三维投影。Host Canvas逐层合成，磨砂对本组件内已绘制的下层内容实际做高斯模糊；完全被近层覆盖的标签不再重复绘制，减少合拢时的模糊重影。它是图形设计的空间合成，不是物理玻璃/PBR渲染。

透明版不会模糊时间线上其它视频；如果需要对外部素材做毛玻璃，还需在该素材或合成背景上另加相应模糊与遮罩。透明模式不因此自动获得外部背景采样能力。

四个示例各12个时刻通过检查；最终20秒双视图抽查20帧，0错误、0警告。满幅背景和文字覆盖检查不完整两类提示保留；采样不能代替逐帧连续播放。

展开和重组的轻提示音为独立音轨，源峰值-9/-8.8 dBFS，增益0.3，时间线估计包络峰值-19.458 dBFS；尚未试听。无配音、无BGM。
