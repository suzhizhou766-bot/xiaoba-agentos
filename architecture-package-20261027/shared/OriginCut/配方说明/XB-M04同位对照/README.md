## 比较什么

同一0019镜头、同一实际源帧2.2022秒（PTS 66066），保持完整画幅、尺寸与位置不变。A为原片显示值；B为同一图像通过Canvas `brightness(1.12)` 得到的显示版本。它是显示值倍率示意，不是曝光EV，不代表用户采用的调色方案，也不宣称新增细节。

源图3840×2160，呈现1280×720设计像素，缩放1/3。图像边界固定[320,220,1280,720]，两边没有分别缩放或变形。0–1秒建立共同参照；1–3秒A停留；3–5秒B停留；两次比较各2秒；5–8秒分界移动，8–10秒整体落定。开始建立参照的1秒也显示原图，但不计入A/B各2秒的比较阶段。

## 文件与可调项

源码：`components/xb-m04-aligned-compare/src/main.js`，来源图：该组件 `assets/source.png`。参数以 `component.json#/propsSchema` 为准：强调色、B显示亮度倍率1.05–1.22、分界方向、落定比例、A/B标签。

默认竖向分界、亮度1.12、落定50%；替代参数横向分界、亮度1.08。A/B切换提示相同源音效、相同0.30增益；第三个提示用于进入分界比较，三次落位0.92、2.92、4.92秒。

更换真实比较材料时需准备已对齐的同场景版本，并改造来源输入，不要把异场景图像换上去冒充严格前后对照。当前实现针对同一来源的两个显示版本，不提供自动配准、画质评分或胜负判断。
