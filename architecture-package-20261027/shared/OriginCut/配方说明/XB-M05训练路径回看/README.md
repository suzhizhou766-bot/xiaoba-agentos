## 这是模拟录像

小样使用自主生成的二维模拟训练录像，全程标明“模拟训练录像·非实拍”“无自动追踪或战术判断”。没有提供真实训练录像或经教练确认的战术结论，本次完成的是回看表达及精确时间对应能力。

原生视频与透明路径图形独立分轨：先正常播放，再0.4倍慢放并标注，随后撤掉路径正常回看一次。路径不遮盖对象主体，观察区只作弱提示。

## 精确回放映射

| 序列时间 | 源视频关系 |
|---|---|
| 0–2.4 | PTS 0–72000，正常速度 |
| 2.4–3 | 保持末帧PTS 71000 |
| 3–9 | 同一PTS范围，用6秒播放，0.4倍 |
| 9–9.6 | 保持末帧、逐渐撤去路径 |
| 9.6–12 | 同一PTS范围，去标注正常回放 |
| 12–14 | 无标注末帧停留 |

图形按同一源帧时钟量化，使用 `floor(sourceSeconds×30)`，上限71。源帧计数固定在画面旁，字幕与导航不跟随对象移动。提示音在2.92、9.52秒，增益0.35。

调整回放倍率r时，须同步修改视频retime、图形参数与第二次提示音：慢放结束 `3+2.4/r`，去标注回放开始 `3.6+2.4/r`，回放结束 `6+2.4/r`，最后停留 `8-2.4/r`；提示音为去标注回放开始前0.08秒。只改图形参数会失去对应关系。总长仍14秒。
