前12秒为浅底黑点、低机位和轻微循环漂移；后12秒为参考代码里的灰蓝小点、静止镜头，采用透明底叠在序列浅色背景上。背景素材保持静音。

## 与给定代码的关系

沿用40列×25行共1000个点、X间距1.5、Z间距2、地面Y=-2的空间结构。用户循环的x=-20…19、z=-12…12与组件默认位置对应。采用一个BufferGeometry、一个THREE.Points对象，无第二个渲染器或独立计时器。

原始PointsMaterial未提供圆形纹理时是方形点精灵。本组件使用ShaderMaterial，通过gl_PointCoord计算圆形覆盖并裁掉圆外像素，边缘渐变抗锯齿；点径随视空间深度衰减，远端另有透明度淡出。它是对给定方案的实现，没有依据尚未提供的原视频宣称逐帧复刻。

默认点径0.14世界单位，便于1080设计画面阅读；`reference-code`示例保留给定0.08、颜色#4A5568、透明度0.6。黑点示例为#151515、透明度0.8、点径0.18、镜头高度7。点颜色和最终观感还受透明度、远处淡出及底色影响。

## 文件与参数

- 源码：`components/xb-b01-perspective-dotfield/src/main.js`。
- 参数唯一来源：该目录 `component.json#/propsSchema`。
- 可调：行列数、横纵间距、地面高度、点大小和颜色、透明度、镜头高度与距离、垂直视角、镜头朝向、漂移幅度、远处淡出距离、背景开关及颜色。
- 四个声明示例：default、reference-code、dark-dots、transparent。
- `backgroundEnabled=false`输出透明点阵，底色交给下方原生轨道或序列背景；黑点不宜叠在同样很暗的画面上。

镜头按源时间进行12秒周期的轻微水平及纵深漂移，0为静止。循环由sin/cos直接求值，不积累帧间状态；倒着寻帧与直接跳转沿用同一时间关系。默认1000点，允许参数范围最多64×48=3072点；目前实际检查了四个声明示例，没有作整段实时帧率或所有参数组合性能承诺。
