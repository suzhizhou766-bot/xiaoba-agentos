# XB-V02｜三维图层拆解

三张半透明面板沿真实三维纵深展开、停留、重组；标签由三维锚点投影，合拢时隐藏后层标签。

这是依据用户提供 HTML 制作的 OriginCut 项目本地组件，未对原始参考视频做逐帧复刻验证。画幅 1920×1080，每段 8 秒。

总览：[8–16 秒](origincut://v1/sequence/seq_2p8trg484mzlh0?revision=3)。组件 ID：`xb-v02-exploded-layers`。

## 使用

在项目组件列表找到「XB-V02｜三维图层拆解」；放入目标序列后可单独移动、裁切、设置参数。背景和章节名可关闭，作为透明叠加使用：`backgroundEnabled=false, showChapter=false`。背景关闭也会关闭点阵。

`gridTimeOffset` 控制点阵的起始时间；总览以各段开始秒数为偏移，保持网格连续漂移。`entrySeconds`、`exitSeconds` 控制进出场。

## 可调参数

- `layerLabels`：默认 `["01 / bg.js · 星空粒子底图", "02 / spark.js · 火种核心动量", "03 / post.js · 泛光与景深"]`。
- `title`：默认 `"Anthropic 火种"`。
- `subtitle`：默认 `"WebGL 自研着色器直出 · 无现成素材"`。
- `separation`：默认 `3`。

## 边界与检查

- 文案、评论和终端标题沿用参考输入；画面中的模型名是参考文案，不是本次调用模型的声明。
- 波形为示意动画，不读取实际音频；柱图为参考数组，均分自动计算；标尺的7.81是独立单项演示。
- 3D 面板使用 Three 几何与透视相机；标签为锚点投影的二维注释，材质为半透明视觉处理。
- `default`、`transparent` 两种示例各12个时刻通过准入检查。总览完成全范围32帧及边界/逆序12帧抽查；抽查不能代替连续播放与音效试听。
- 改长文案、图层间距、播放速度后重新预览；固定8秒的配方并未保证任意参数组合都不需调整。
