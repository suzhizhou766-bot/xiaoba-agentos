# 小八 Remotion 工具

安装目录：`/Users/suzhizhou/Documents/私人助理/工具/Remotion`

这是可在本机运行的 Remotion 项目和 Studio，基于官方 Hello World 模板。Remotion 与 @remotion 包版本均锁定为 **4.0.535**；依赖通过官方 npm 仓库安装，精确版本保存在 `package-lock.json`。

## 启动

双击 `启动Remotion.command`，终端会启动 Studio 并打开浏览器。地址为 `http://localhost:3330`。关闭时在启动它的终端按 Control+C。没有配置开机自启。

也可以在此目录运行：

```sh
npm run start
```

## 编辑与导出

`src/Root.tsx` 登记了 HelloWorld、Logo、Title 三个 composition；画面组件在 `src/HelloWorld.tsx` 和同名子目录中。可以让小八或其它编程 Agent 在此目录修改 React/TSX，然后在 Studio 检查。

双击 `导出示例.command` 可导出官方示例，输出在本目录 `out/`，文件名包含时间与进程号；导出完成后自动打开视频。

```sh
# 查看代码和类型检查结果
npm run lint

# 指定文件名导出；执行前检查目标文件是否已存在
npm run render:demo -- out/my-video.mp4 --codec=h264

# 检查所有 Remotion 包版本
node node_modules/@remotion/cli/remotion-cli.js versions
```

依赖需要重装时运行 `npm ci`。`.npmrc` 将安装缓存放在本项目 `.runtime/npm-cache`，避免依赖当前用户全局 npm 缓存的权限。启动脚本为 Finder 设置了本机现有 Node/npm 路径。
