
桌面端：在 Finder 双击本目录 `启动Antigravity走VPN.command`，或者执行：

入口每次读取系统当前的 HTTPS 代理，只接受本机代理地址并检查端口是否可连接；不可用时停止启动，不静默回退直连。HTTP/HTTPS/ALL_PROXY 的大写和小写版本只设置给本次启动的程序及其子进程；`localhost`、`127.0.0.1`、`::1` 保持本地回传。桌面端还设置 Electron 的 HTTP/WebSocket 代理参数，未关闭证书验证。

桌面端若已运行，入口会提示先正常退出，不擅自结束用户会话，也不声称能修改既有进程的环境。原 Dock 图标或 Finder 中原应用的独立新启动不一定包含这些参数，应使用本 VPN 入口；唤起已有进程时沿用该进程的启动环境。

## 由用户执行的终端持久启用

小八 `AGENTS.md` 第 6 节规定 Codex 不接持久配置修改。本轮未修改 `.zshrc`、应用配置、原二进制、认证或 AgentOS 发布/后台配置。下列步骤只由用户本人在 zsh 终端执行：

```sh
source '/Users/suzhizhou/Documents/私人助理/工具/AGY-VPN/启用并固定.zsh'
```

它在 `.zshrc` 末尾仅追加一条（已存在则不重复）source 行，并立即在当前终端启用两个函数：`agy` 启动 CLI，`antigravity` 启动桌面端。其余命令的代理环境不改变；不创建备份。`.zshrc` 为符号链接或原文件语法失败时会拒绝自动追加，交用户核对。

只在当前终端启用、而不写任何持久配置，可改为 source `启用当前终端.zsh`。

本方式不替换官方 `~/.local/bin/agy`，因此原更新器仍管理原二进制；后台程序若用绝对路径直接调用官方二进制，不会自动使用终端函数。本轮未变更 AgentOS 后台或生产路由。

官方账号地区更正入口：[国家/地区关联申请](https://policies.google.com/country-association-form?hl=zh-CN)。需登录 AGY 使用的同一账号，依页面说明申请与实际居住情况相符的更正，等待 Google 审核。Google 官方账号社区管理员说明：老账号通常参考过去一年主要使用地区，搬迁后的自动更新可能约一年；这不是人工申请的固定审核时限。来源：[Google 官方账号说明](https://support.google.com/accounts/community-guide/389960921?hl=en)。本轮表单跳转至登录，未查看登录后的私人内容，也未提交申请。

账号关联国家目前依据用户自行核对后的“中国”反馈，没有读取私有账号资料。手动选择服务条款网页的国家版本不等于变更账号国家；应在已登录对应账号的官方关联页面确认。地区关联审核与原来的服务条款停用申诉是两条不同流程，批准地区更正不保证解除另有的账号停用。
