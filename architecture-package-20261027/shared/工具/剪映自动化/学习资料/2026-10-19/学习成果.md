## 学习方法与证据等级

采用“当前官方功能 → 本机面板定位 → 桌面案例定向抽查 → 参数与验收卡”的方式。长课只查所需章节；旧课用于理解原理，菜单、快捷键和权益以本机为准。阅读目录不算观看视频，看到面板不算已经完成效果制作。

本轮只切换面板、选择已有片段并阅读设置；全局设置以取消退出，未主动修改666的剪辑参数、字幕、转场或素材。打开时仍出现历史素材库220项未链接提示，取消后当前30秒时间线可显示；这不是本轮修复的对象。

## 可以直接复用的技术步骤

1. **结构与节奏**：先定30秒中开场、展开、高潮、收尾的任务，再挑素材、排长短镜头。用主体位置、动作方向、构图或色彩关系连接镜头。鼓点是参考，文字阅读和内容变化也决定切点。
2. **转场和特效**：转场放两段连接处，特效可单独覆盖指定时段。选择后调整时长并播放前后几帧，检查主体是否被遮住、是否露黑边、是否过亮。炫光适合强调，推近适合方向承接，叠化适合时间或情绪过渡；不默认每刀使用同一效果。
3. **关键帧**：先设起止状态，再决定中间节奏；缓入缓出影响运动速度，不是只增加关键帧数量。复制属性前明确复制范围，避免覆盖构图、调色或不该复制的蒙版。曲线编辑在本机尚未完成制作验证。
4. **蒙版**：准备上下两层画面，选上层蒙版，调整位置、角度、尺寸和羽化；再做显露动画。主体附近检查边缘。羽化值的单位和范围随面板变化，不抄“统一羽化50”之类数字。
5. **曲线变速**：先确定要强调的动作点，再安排快慢段并复查音画与时长。60fps素材放30fps时间线，0.5倍速可按原始帧逐帧慢放；120→30为0.25倍。低帧率强行慢放仍可能顿挫，补帧需另查运动边缘。
6. **调色**：检查输入色彩空间 → 曝光/白平衡 → 镜头匹配 → HSL局部颜色 → 曲线/色轮 → 最后适量风格。建筑和室内保留材质光泽、反射、冷暖和明暗分离，不能把统一压灰当成高级。
7. **文字**：先校对原文、断句和阅读时间，再做统一字号层级、重点词和动画。入出动画不能挤占正文全部停留时间；字幕批量套样式后再检查逐条溢出与遮挡。
8. **声音**：优先保证人声可懂；音乐在对白时降低，重音、转场与环境声服务内容。音量增益dB、峰值dBFS和综合响度LUFS是不同量，不互相替代。完整成片需实际听音，不能仅凭波形判断好听。
9. **交付**：按目标用途选择比例、分辨率、帧率、编码与码率；导出后核验时长/帧数/音轨，并看转场边界和文字。24fps不自动等于电影感，30→60也不自动增加真实动作细节。

## 参数起始表（我的制作建议，尚非本轮成片验证）

以下用于30fps照片快闪的试剪起点，不是官方统一参数；应根据音乐、画面和阅读调整。

| 项目 | 起始值/算法 | 验收重点 |
| --- | --- | --- |
| 时间精度 | 30fps下1帧约33.333ms；30秒=900帧 | 所有切点落在帧格，避免累积时长误差 |
| 快切镜头 | 8–16帧，约0.267–0.533秒 | 连续快切后保留能看清主体的停留镜头 |
| 强调停留 | 24–45帧，约0.8–1.5秒 | 长文案应另给更长阅读时间 |
| 短转场 | 4–8帧，约0.133–0.267秒 | 先检查片段时长与可用余量；不要盖住整段主体 |
| 照片轻运动 | 可从100%→103%–108%试起 | 起始100%须已铺满画面；检查裁边和主体，不机械套给所有照片 |
| 节拍换算 | 每拍秒数=60/BPM；每拍帧数=帧率×60/BPM | 节拍未必整数帧，长片需累计取整；112.5BPM在30fps下恰为16帧/拍 |
| SDR | 确认输入后使用Rec.709流程 | HDR/HLG/LOG需先明确转换，不能直接照套 |
| H.264上传参考 | YouTube官方：1080p 24/25/30为8Mbps，48/50/60为12Mbps | 只作为该平台SDR上传建议；不外推成所有平台、HEVC或母版标准 |
