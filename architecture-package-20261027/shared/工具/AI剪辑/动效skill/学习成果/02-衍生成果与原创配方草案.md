# 衍生成果与原创配方草案

日期：2026-10-22  
状态：本次独立设计的规格草案。没有实现配方代码、没有接入 OriginCut、没有完成用户题材验收。

## 1. 要做出的第一项成果

先做六张“小八自己定义的动效配方”，每张配方交齐：

- 一段短预览，以及入场、信息变化、落定三张关键帧。
- 用途、适用与不适用的材料。
- AI 可读的输入与参数说明，人可操作的调节项。
- 时间锚、阅读停留与声音落点。
- 已验证的画幅、帧率、导出方式和可编辑层级。
- 失败样例、技术检查和用户采用状态。

预览和最终渲染应读取同一份配方与参数。初期先确定一个实现后端，不同时做多个工具版本；最终平台按现行方向考虑 OriginCut，其原生实现需要在该宿主内独立适配。

## 2. 每张配方的共同字段

| 字段 | 记录什么 | 为什么需要 |
|---|---|---|
| 识别信息 | 稳定编号、中文名、版本、状态 | 人和 AI 能准确指向同一个版本 |
| 表达意图 | 要让观众理解什么关系 | 按内容选择效果 |
| 输入材料 | 原片、图片、文本、数据、标注区域 | 先检查材料是否足以支持动作 |
| 事实依据 | 结论或数据对应的来源 | 修改事实时能找到受影响内容 |
| 画面主次 | 主体、参照物、屏幕固定层 | 避免主体被字幕和装饰挤掉 |
| 调节项 | 默认、单位、范围、变化后果 | 调参可预测，不只暴露数字 |
| 时间 | 入场、变化、停留、离场与时间锚 | 避免刚看清就切走 |
| 声音 | 可选音效类型与落点 | 声画使用同一个事件 |
| 连续关系 | 从上镜带来什么、向下镜留下什么 | 让转场服务内容 |
| 输出能力 | 有无 alpha、分轨、源码或原生组件 | 交付前说明编辑边界 |
| 适配证据 | 测过的比例、语言、帧率和引擎 | 避免把一个样例当成通用能力 |
| 验收 | 机器检查、目视检查、实际采用 | 区分技术通过与创意采用 |

建议时间契约：在内部统一采用“起点包含、终点不包含”的区间；保留帧率的分子与分母。把句段、词、音乐拍点等锚解析为边界后，再计算长度。不同工具采用其它区间习惯时，由适配层明确转换。

这是一项新设计建议，尚未形成可执行格式。

## 3. 六张原创配方规格

### XB-M01｜实拍焦点交接

**意图：** 让一个实拍对象自然成为图解中的主体，随后返回原片。

**输入：** 一段原片、一个已标注对象区域、允许的停帧或时间范围、短说明。  
**动作：** 原片保留空间 → 对象边界提示 → 关联图解在邻近位置展开 → 对象与图解共同停留 → 图解收束到同一对象。  
**调节：** 图解相对位置、边界提示强度、背景压暗量、展开方向、停留时间。  
**时间：** “对象被提及”驱动提示，“关系被说明”驱动展开，读图完成后返回原片。  
**声音：** 可选轻提示或动作收束声，响度不能压住解说。  
**验收：** 原片主体形态不变；提示与对象对齐；字幕无遮挡；往返有可辨认的对应关系。  
**限制：** 运动对象需要可靠跟踪；遮挡严重、边界无法确认时改用停帧。单张图不支持推断不可见结构。

### XB-M02｜证据窗口

**意图：** 让“一个结论来自哪里”在画面上可追踪。

**输入：** 一条经确认的结论、一份来源材料、对应段落或图表区域。  
**动作：** 先给观察问题 → 展示来源局部 → 标出支持信息 → 结论落定 → 来源缩成可回看的注记。  
**调节：** 来源窗口比例、标注位置、阅读时长、结论字数上限。  
**时间：** 阅读窗口先获得足够停留，结论随后出现；不能用快扫代替可读证据。  
**验收：** 高亮区域确实支持结论；数字、单位与来源一致；不截掉限定条件。  
**限制：** 仅展示一张论文或报告封面，不足以证明画面上的具体数字。

### XB-M03｜因果接力

**意图：** 在连续空间里讲清“条件改变后，结果怎样变化”。

**输入：** 已核实的因果说明、起始状态、变化因素、结果状态。  
**动作：** 一个共同对象保持可辨认 → 条件变化作用于对象 → 结果发生 → 对象移位成为下一段的参照。  
**调节：** 关系数量、动作方向、因素强调、对照是否保留。  
**时间：** 条件出现、作用发生、结果落定分别锚定到相应讲解段。  
**验收：** 动作方向与叙述一致；观众能辨认哪个因素被改变；不把相关性画成已证实因果。  
**限制：** 多变量或证据不足时应改为并列比较，并显式保留不确定性。

### XB-M04｜同位对照

**意图：** 让观众在稳定参照下看清两种结果的差别。

**输入：** 两份可比较材料、对齐依据、比较维度、不能改变的内容。  
**动作：** 先建立共同参照 → 逐次切换同一局部或并置显示 → 只强调目标差别 → 回到整体。  
**调节：** 对照方向、视图比例、局部放大范围、标注强度、两边停留长度。  
**时间：** 两边获得可比较的阅读时长，不能以不同停留或缩放人为制造优劣。  
**验收：** 位置、比例和显示条件可比；标明原始尺寸与呈现尺寸；文字与结构细节可检查。  
**限制：** 非同场景图片不能冒充严格的前后对照；局部放大不宣称产生了新增细节。

### XB-M05｜训练路径回看

**意图：** 帮助观众在训练录像中找到一条经确认的动作或移动路径。

**输入：** 原录像、教练确认的对象与路径、需要回看的时间范围。  
**动作：** 先看正常速度 → 在关键片段标出路径与观察区域 → 回放验证 → 去掉标注再看一次。  
**调节：** 回放速度、路径线宽、标记持续时间、区域透明度。  
**时间：** 使用录像中的实际帧与事件；图形跟随对象，字幕和导航固定在屏幕。  
**验收：** 路径不穿帮；不挡关键动作；标注与原片时间一致；技战术解释经教练核实。  
**限制：** 这是讲解表达规格，不代表已具备自动球员跟踪、三维战术重建或自动判断能力。

### XB-M06｜论点压缩

**意图：** 把长内容改为短片时，保留一个完整、可理解的论点。

**输入：** 已确认的长版内容、目标时长、一个核心问题、必要证据与结论。  
**动作：** 提出问题 → 保留最必要的机制或证据 → 给出有边界的结论 → 留下进一步了解的入口。  
**调节：** 证据数量、示例复杂度、阅读时长、尾部停留。  
**时间：** 按理解顺序重新编排，不能把长版整体加速到目标时长。  
**验收：** 短版独立可懂；没有因删除限定条件而改变原意；结论仍有支持。  
**限制：** 无法在目标时长讲清时，应缩小论题，不通过堆字和加速配音解决。

## 4. 第一轮三个最小试验

| 试验 | 目的 | 材料 | 必须留下的证据 |
|---|---|---|---|
| A：实拍焦点交接，约 10 秒 | 验证实拍与图解的连续关系 | 一段用户确认的原片、一个对象 | 原片/输出对照、对齐帧、一次参数调整前后 |
| B：同位对照，约 10 秒 | 验证比较是否公平、差别是否清楚 | 一组用户确认可比较的图片 | 对齐依据、同尺寸关键帧、文字与结构检查 |
| C：一个论点，约 30 秒 | 验证文案、配音锚与画面能否协同 | 经确认的短文案、完成的配音 | 时间锚表、成片、最弱时刻的修改记录 |

先做小样，再确定哪些参数值得开放、哪些限制必须保留。每次只验证少数关键假设，记录失败条件。没有完成上述试验前，不把六张草案称为“小八已拥有的六个动效”。

## 5. 更远的成果

- **系列知识片：** 同一信息结构和术语体系，跨期保持一致。
- **一题多交付：** 讲解片、短预告、关键帧图文与演示稿共用已确认内容。
- **可交互讲解：** 让观众手动改变条件、查看结果；这需要独立的交互和状态设计。
- **配方浏览与调用：** 先有稳定的小样和规格，再设计人和 AI 共用的浏览入口。
- **跨工具适配：** 共用内容、时间和参数含义，在各工具独立实现；导出时明确保留了哪些编辑层。

这些方向是成果规划，尚未创建对应产品、服务、生产组件或监看中心入口。
