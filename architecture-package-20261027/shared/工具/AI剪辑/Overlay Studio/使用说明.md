# Overlay Studio（小八部署说明）

给口播视频加动效层的本地编辑台：AI 读 SRT 字幕稿，从 20 张做好的动效卡里挑卡、对时间，生成编排 JSON；在编辑台里逐卡微调；导出**透明 ProRes 4444 MOV（29.97fps）**，拖进剪映置顶轨道盖在原片上，原片不重编码。

- 上游：https://github.com/jeszhou/overlay-studio ，部署提交 `e35e1aff9dae3b3addc21f68f3bcd51f95bdc1a8`（2026-10-17），motion-playground 1.1.1
- 部署：2026-10-20，用户授权克隆、`npm ci`、下载 puppeteer 无头 Chrome，并授权在浏览器面板里点同意授权协议

## 启动与关闭

| 操作 | 方法 |
|---|---|
| 启动 | 双击 `启动.command`（后台起服务并打开浏览器）；Agent 用 `"…/Overlay Studio/启动.command" --no-open` 只起服务 |
| 访问 | http://localhost:5177/ （只监听本机） |
| 关闭 | 双击 `关闭.command` |
| 日志 | `logs/server.log`，进程号 `logs/server.pid` |

- 端口 **5177** 是上游写死的（`strictPort`），被占时启动失败而不是换端口；不与监看中心 8799、Remotion 3330 冲突。
- 不开机自启。不要用仓库自带的 `motion-playground/启动 Overlay Studio.command`：它走 PATH 里的 npm，拿不到小八的 Node 和 Chrome 位置。
- 首次在某个浏览器打开会弹授权协议门，滚到底点「我已阅读并同意」（同意记录存在该浏览器的 localStorage）。

## 运行环境（全部复用或放在 配置/，见 配置/环境索引.md）

- Node：`配置/node` 24.19.0（上游要求 ≥22.12）
- ffmpeg / ffprobe：`配置/bin`（7.1，含 prores_ks、libvpx-vp9；ffprobe n4.4.1）
- 无头 Chrome：`配置/puppeteer/`（puppeteer 25.3.0 下载的 Chrome 150.0.7871.24 及 headless-shell，约 546MB）；`motion-playground/.puppeteerrc.cjs` 和启动脚本都指向这里
- npm 缓存：`配置/npm-cache/`
- 依赖：`motion-playground/node_modules`（按 `package-lock.json` 精确安装，约 144MB）

## 怎么用

1. 拿到 SRT：剪映「识别字幕」后导出，或用 Whisper 转写。
2. AI 编排：让 Agent 在**仓库根目录**（本目录）读取 `.claude/skills/overlay-fx-generator/SKILL.md`（Codex 等读 `.agents/skills/…`），说“根据 SRT 生成动效”，得到 `xxx-overlay.json`。不需要 API Key，用的是当前 Agent 自己的模型；编排质量随模型强弱变化。
3. 编辑台：拖入 JSON 和视频（建议 H.264），逐卡调位置、大小、颜色、字体、快慢；左下角体检浮窗提示问题。
4. 导出：点「⬇ 导出透明 MOV」，成品在 `motion-playground/exports/output/`（同时出一份 VP9 透明 WebM，剪映不认 WebM 透明，给网页/达芬奇用）。
5. 剪映：把 MOV 拖到原片上方轨道。

命令行体检：在 `motion-playground` 里 `PATH=/Users/suzhizhou/Documents/私人助理/配置/node/bin:$PATH npm run -s lint:overlay -- 编排.json --duration 秒数`。

## 在小八里的定位

“SRT → 透明动效层”这一步，属于口播类视频的包装环节。与已有工具分工：`工具/剪映自动化` 读写剪映原生草稿；`工具/AE调用` 做复杂 MG；`工具/Remotion` 做可复现的整片合成。Overlay Studio 只出一条叠加层文件，交给剪映合成。

## 注意

- **磁盘**：导出先出 PNG 序列再合成，1 分钟成片约 4.5GB 中间文件；成品 MOV 也大（28 秒示例约 495MB）。
- **路径**：上游建议放纯英文、无空格路径。本目录含中文和空格，2026-10-20 实测导出正常（macOS 下参数按数组传给 ffmpeg）；若以后某步因路径失败，再考虑换英文路径。
- **字体**：仓库不带字体，缺省用系统字体渲染，排版和粗细会与作者预览不同。需要时把字体放进 `motion-playground/src/assets/fonts/`（文件名即字体名），推荐思源黑体（SIL OFL）。
- **联网**：运行时界面会从 Google Fonts 加载 IBM Plex 界面字体（离线自动退回系统字体）；顶栏「官网」是上游作者的推广链接。其余都在本机。
- **更新**：上游文件更新会被覆盖。小八自己加的文件是 `启动.command`、`关闭.command`、`使用说明.md`、`界面截图.jpg`、`motion-playground/.puppeteerrc.cjs`、`logs/`，都不在上游仓库里。更新后要重新 `npm ci`（带上 `配置/` 的 PATH、`npm_config_cache` 和 `PUPPETEER_CACHE_DIR`）。
