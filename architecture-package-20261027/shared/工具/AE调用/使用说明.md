# AE调用：小八控制 After Effects 的工具箱

部署日期：2026-10-17（Claude 远程会话安装，未改个人客户端配置、未改 AE 安装目录）。
适用：Adobe After Effects 2026（26.2.1），macOS。

## 这里有什么

| 内容 | 位置 | 是什么 | 谁用 |
|---|---|---|---|
| after-effects-mcp | `after-effects-mcp/` | 开源 MCP 服务（a-y-ibrahim 增强版 v1.13.0，提交 e9ffbed，MIT）。57 个工具：查看合成/图层、看画面帧、关键帧、表达式、特效与预设、音频驱动动画、素材导入与重链、渲染队列与 aerender 后台渲染、执行任意脚本 | 本机 Agent（Claude Code、Codex 等）通过 MCP 调用 |
| adobe-agent-skills | `adobe-agent-skills/` | 开源 Agent 技能（aedev-tools，提交 00f131e，Apache-2.0）。34 个现成脚本 + 9 篇规则文档（关键帧、表达式、特效、渲染、批量操作等） | 本机 Agent 用 `runner.sh` 直接跑；远程 Agent 经队列桥接调用 |
| 队列桥接 | `队列桥接/` | 小八自己的桥接脚本：`xk_lib_call.jsx`（队列里调用 34 个脚本）、`health_check.jsx`（AE 状态体检）、`open_mcp_bridge.jsx`（检查 MCP 桥接面板开没开；脚本打不开面板） | 所有 Agent |
| 接入配置 | `config/` | Claude Code、Codex、通用 MCP 的配置片段 | 用户或本机 Agent 复制到客户端配置 |

另有一条已在用的通道：**文件队列**（`工作区/ae-scripts/queue/`）。AE 启动时由 `/Applications/Adobe After Effects 2026/Scripts/Startup/xk_bootstrap.jsx` 加载 `工作区/ae-scripts/xk_watcher.jsx`，每秒检查队列，执行后移到 `done/`，日志在 `logs/`。

## 三条通道怎么选

1. **MCP（首选，本机 Agent）**：结构化工具、看画面帧、渲染状态都现成。前提是桥接面板开着。
2. **runner.sh（本机 Agent 有终端时）**：`bash adobe-agent-skills/skills/after-effects/scripts/runner.sh --background <脚本.jsx> '<参数JSON>'`，结果打印到终端并写 `/tmp/ae-assistant-result.json`。本地修过两处（2026-10-17）：版本识别把 “Adobe After Effects 2026” 按空格拆成四个版本；set -e 下看门狗的 wait 返回 143 让脚本不输出结果就退出，残留的 sleep 还占着输出管道 60 秒。改动只在 runner.sh，`git diff` 可看。
3. **文件队列（任何能写工作区的 Agent，包括远程 Claude）**：把 .jsx 写成临时文件再 `mv` 进 `工作区/ae-scripts/queue/`，读 `logs/<脚本名>.log`。要用 34 个现成脚本时：

   ```js
   $.evalFile(new File("/Users/suzhizhou/Documents/私人助理/工具/AE调用/队列桥接/xk_lib_call.jsx"));
   xkLibCall("comp-detail.jsx", {compName: "主合成"}, "comp-detail");   // 结果在 logs/comp-detail.json
   ```

三条通道可以同时开，互不干扰（各自轮询各自的文件夹）。

## 一次性安装（需要用户本人操作）

自动安装进 AE 程序目录、改个人客户端配置都属于需要用户亲手做的长期改动，Agent 不代做。

1. **装桥接面板**：把 `after-effects-mcp/build/scripts/mcp-bridge-auto.jsx` 复制到 `/Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/`，重启 AE。之后从「窗口」菜单最底下（菜单很长，要往下滚）点 `mcp-bridge-auto.jsx` 打开，面板开着、Auto-run commands 勾选着才能用 MCP。脚本打不开这个面板：`app.findMenuCommandId` 对所有 ScriptUI 面板都返回 0；用 `$.evalFile` 直接跑面板脚本会弹出不响应的浮动窗口，还会让队列监听器停掉（只能重启 AE 恢复），不要这样做。本机 Agent 可以用电脑操控（全屏模式）点这个菜单项。
2. **接入 MCP 客户端**（按需，任选）：
   - Claude Code：把 `config/claude-code.mcp.json` 里的 `after-effects` 一项合并进 `/Users/suzhizhou/Documents/.mcp.json`（与达芬奇同一个文件）。
   - Codex：把 `config/codex.config.toml` 追加到 `~/.codex/config.toml`。
   - 其他 Agent：照 `config/通用MCP片段.json`。
   解释器用小八统一的 Node（`配置/node/bin/node`，24.19.0）。
3. **AE 偏好**：「设置 → 脚本和表达式 → 允许脚本写入文件和访问网络」保持勾选（已确认开启）。

## 上班检查（“上班了小八助理”之后、做 AE 任务前）

1. AE 在运行吗：看 `工作区/ae-scripts/logs/_heartbeat.txt` 的时间，10 秒内更新过说明 AE 开着且队列在工作。
2. 往队列放 `队列桥接/health_check.jsx`，读 `logs/ae-health.json`：AE 版本、当前工程、活动合成、`bridgePanelInstalled`（面板文件装没装）、`bridgePanelRunning`（面板开没开）、`bridgeAutoRun`（Auto-run 勾没勾）。
3. 用 MCP 的 Agent：调用 `check-bridge`。面板没开，请用户从「窗口」菜单最底下（菜单很长，要往下滚）点 `mcp-bridge-auto.jsx`，或本机 Agent 用电脑操控去点；不要往队列放面板脚本。
4. 心跳不更新：AE 没开，提示用户打开 AE，不要自行拉起。

## 安全审查结论（2026-10-17）

- after-effects-mcp：无外连网络；只在渲染时启动 `aerender`、音频转换时启动 `ffmpeg`。桥接面板会执行共享文件夹 `~/Documents/ae-mcp-bridge/` 里的命令，所以能写这个文件夹的程序都能控制 AE，只在本机使用。
- adobe-agent-skills：脚本里没有调用系统命令或联网。`runner.sh` 用 osascript 让 AE 运行脚本；出错时会把错误文字拼进一条 shell 命令写日志，属于本机低风险，Socket 扫描给的“警告”大概率指这里。
- 两个项目里都存在 `eval`，用途是执行 Agent 下发的脚本，属于设计本意。

## 操作规范

- 改动都包在撤销组里；删除图层或素材、覆盖已有渲染文件、关闭未保存工程前先问用户。
- 不开机自启新东西、不装常驻进程；已有的队列执行器之外，新的常驻组件要用户同意并亲手安装。
- 写脚本的经验与表达式配方见技能 `skills/after-effects-control/SKILL.md`。

## 升级

- after-effects-mcp：目录里 `git pull`，然后 `npm ci --omit=dev` 和构建（构建需要开发依赖：`npm ci && npm run build && npm prune --omit=dev`），再把新的 `build/scripts/mcp-bridge-auto.jsx` 复制进 ScriptUI Panels 并重启 AE（版本不一致时 `check-bridge` 会报警）。
- adobe-agent-skills：目录里 `git pull`。
