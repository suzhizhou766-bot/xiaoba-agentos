# REA 本机部署与使用

版本：`rea-agents 6.5.0`。入口：`/Users/suzhizhou/Documents/私人助理/工具/REA逆向/bin/rea`。安装方式是官方支持的项目内 npm（软件包管理器）安装，精确依赖与 `package-lock.json`（锁文件）均在此目录。复用 `私人助理/配置/node/bin/node` 24.19.0；没有全局安装、改系统解释器或修改个人 Agent 配置。

2026-10-17 技能更新：在小八主入口输入“调用 REA”后，信息不全时会主动提供分析对象、重点和授权选项，再补齐应用名或路径。已说明的信息不重复问；需求齐全后直接按授权范围执行。具体选项见技能 `references/guided-intake.md`；提问组件不可用时使用编号列表。

```sh

"$REA" --version
"$REA" mcp doctor --json
"$REA" analyze-javascript-application "/绝对路径/已授权应用目录或app.asar" --json
"$REA" inspect-artifact "/绝对路径/已授权.app" --json
"$REA" inspect-macho "/绝对路径/已授权.app" --json
```

技能正文在 `/Users/suzhizhou/Documents/私人助理/skills/rea-reverse-engineering/SKILL.md`，包含适用场景、输入输出、macOS 工作流、官方来源、安全约束、小八多个 Agent 协作及故障处理。是否已正式进入小八 `skill-match`（技能匹配），以 `deployment.json` 的 `skill_registration`（技能登记状态）和现场查询为准；文件存在不等于正式登记。

MCP（模型上下文协议）服务使用 stdio（标准输入输出）：`"$REA" mcp`。`config/mcp-stdio.json` 是通用客户端配置片段；`config/codex.toml` 和 `config/dsh-cordis.yml` 分别是 Codex、DSH 适配片段。仅保存到本目录，未覆盖个人配置，因此不能声称当前聊天已经直接发现 REA 工具。宿主或后台可立即使用上述 CLI（命令行）入口。个人配置接入需要限定客户端、合并既有配置并重启/重连后再验实际工具调用。

当前验证：自建 JavaScript（双源码）经 CLI 与实际 MCP 调用解析成功；自建 macOS 应用包清单与 Mach-O（原生二进制格式）静态检查通过；不存在的目标被拒绝；分析前后样本哈希一致，样本程序未执行。复验：

```sh
python3 "/Users/suzhizhou/Documents/私人助理/工具/REA逆向/tests/smoke.py"
```

结果写到 `evidence/verification/smoke-summary.json`。该测试不验证真实商业软件、原生反编译、网页交互或 Frida（动态插桩）。Hopper、Ghidra、IDA 尚未配置；需要时在合法获得引擎和许可后单独接入。系统只有 `/usr/bin/java` 启动占位程序不代表已装 JDK（Java 开发工具包）。

安全与维护：只分析自有或获授权软件。REA 不是 sandbox（沙箱）；执行、调试、网络捕获和设备操作必须在实际授权内。安装时禁用生命周期脚本、省略可选 Frida；146 个依赖的仓库签名验证通过，其中 33 个具有已验证证明，安装时 npm 漏洞审计为 0。签名和当时漏洞检查不能保证无未知风险。来源和校验在 `evidence/source-verification.json`，官方原文在 `evidence/upstream/`。

重要本机兼容点：不要把 `TMPDIR`（临时目录）强制设置到此中文路径。已复现 Apple Swift 因该设置退出 -5，继承系统默认临时目录后通过。包装器保留原本 TMPDIR，REA 自己管理系统临时目录中的所有权辅助程序和进程资源；npm 与可重定向缓存留本目录。此安装的隔离指依赖/配置隔离，不是完整的文件系统隔离。

更新先核对官方 https://github.com/morluto/rea 与 npm 的 `rea-agents`，明确选定版本，按技能的维护说明安装并重新验证；不运行此部署不适用的全局 `rea update`（更新器），不启用自启、定时更新或自动发布。模块 `publish_enabled=false`（关闭发布）。本部署不改变小八全局记忆发布策略，不批准任何经验候选。

目录用途：`bin/` 启动入口，`config/` 接入和技能条目，`node_modules/` 已安装依赖，`downloads/` 已校验官方包，`tests/` 自建验证样本，`skill-draft/` 冻结审查源，`evidence/` 来源、审查与测试证据，`cache/` 本工具下载缓存。不是备份或发布包副本。
