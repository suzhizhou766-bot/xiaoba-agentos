# 小八 Director Stage · Web MVP

一个本地运行的三维摄影预演工作台。使用 React + TypeScript + Vite + Three.js / React Three Fiber + Drei + Zustand；提供 Tauri 2 桌面壳骨架。

## 当前制作流程（0.6）

在「导演编译器」勾选 **Gemini Omni 1.1 Flash** 或 **Seedance 2.5** → 导出交接包 → 发给助手 → 助手制作最终首尾帧与对应模型提示词 → 用户去视频平台生成视频。

模型选择按镜头保存，项目 JSON 往返和镜头复制保留选择。旧项目没有默认模型，导出前需选择一次；已选模型自动写入 ZIP / TXT / JSON，不需要在对话中重复说明。未选模型时导出按钮不可用。

面板可展开「提示词教学与使用方法」，查看使用步骤、官方核验摘要、原创模板、首尾帧和运镜写法、参考素材职责、声音与排错。可单独下载指南；离线文档在 `docs/model-guides/`。核验日期为 2026-09-16，不声称穷尽全网或已经实测视频模型。Google API 的具体限制与产品概览分开记录；BytePlus 指南本轮只读取到标题及更新时间，未将其正文作为已验证依据。

ZIP 含 `handoff.txt`、`handoff.json`、项目文件、首尾预演 PNG、`model-guide.md`、`model-profile.json`、`sources.json`、`prompt-writing-task.txt` 和使用说明。指南和制作指令与选中的模型一致。包内预演图仅控制构图，不是最终生成图，也没有自动发送到对话。

每个镜头的视觉说明随项目保存。助手结合角色/场景/风格参考，制作最终首尾图，再按已选模型整理视频提示词。投递时间轴从首帧标记归零；平台不支持所选时长时给出分段方案，不擅自改动运镜设计。

## 五分钟上手

1. 点击「打开」，选择 `examples/demo.xbdirector.json`，载入双人调度示例。空格播放 / 暂停，时间轴尺可拖动定位。
2. 左侧选择角色，在「对象属性」修改位置、旋转、缩放；或按 W / E / R 使用变换手柄。R 模式拖动 X 手柄执行等比缩放。左键环绕编辑视角，右键平移，滚轮缩放。
3. 保持角色选中，点击右侧「摄影机」页签，选择 ECU / CU / MCU / MS / MWS / FS / LS / ELS，按角色包围盒设置构图。「自由观察」用于检查场景；切换「主相机视角」即可与监看一致，点击「操控机位」直接环绕、平移、推拉真实机位。
4. 在 0 秒调整机位 / 视线 / 焦距并打关键帧，定位到另一秒，修改后再次打帧。相机记录完整摄影参数，角色记录位置。可开启「自动打帧」。点击轨道名称右侧菱形也可记录。同对象同一时刻会覆盖；右键已有菱形删除，单击定位。
5. 下方镜头条「＋」复制当前镜头的场景、相机与关键帧为新镜头。切换镜头保留各自修改。项目名和镜头名均可编辑。
6. 设置首帧、尾帧后点击「预演首尾帧」导出两张 PNG；监看右下方图片按钮导出当前画面。辅助线只用于监看，不进入 PNG。
7. 「导演编译器」导出中文提示词 TXT 与结构化 JSON；「保存项目」导出包含所有镜头、参数、关键帧和内嵌模型资源的 `.xbdirector.json`。

**由小八监看中心提供页面时，草稿自动保存到这台电脑的本机工程库（`工程库/` 目录：草稿是 `drafts/` 下的文件，模型和图片按内容哈希在 `assets/` 下只存一份，工程文件里只留引用），换浏览器、清浏览器数据都不会丢；浏览器里原有的草稿会在第一次打开时搬过去一份。用开发服务或单独打开构建产物时仍用浏览器的 IndexedDB。**

**项目修改已支持基于 IndexedDB 的本机草稿自动保存与会话隔离恢复；编辑发生时自动防抖持久化，意外刷新或关闭可自动恢复。离开前也可随时点击「保存项目」导出独立工程。**

## 素材导入约定

- 推荐单文件、自包含 GLB。GLTF 请一次选择 `.gltf`、`.bin` 和使用的贴图；支持拖入多个文件，不支持拖入目录。
- 外部资源按文件名匹配，重名或缺失会给出错误。网络资源不会自动下载；请先把依赖准备为本地文件。
- 单位按米，Y 轴向上。模型保留原比例并放到地面；过大 / 过小可调等比缩放。
- 导入的 GLTF 骨骼模型显示默认姿态；不播放模型自带动画。
- 本版未配置 Draco / KTX2 / Meshopt 解码器。需要相应解码器的压缩资产请先导出为普通 GLB / GLTF。
- `examples/block.gltf` + `examples/block.bin` 是本项目自制的导入测试方块。
- 素材内嵌为 Data URL 会使项目 JSON 体积增加。大型资产会消耗较多内存；后续迁移为项目目录 + 二进制资源文件。

## 时间轴与摄影约定

- 相机关键帧记录位置、视线点、焦距、传感器宽、滚转、光圈、对焦距离；数值按关键帧的「运动曲线」插值，可选匀速、缓入、缓出、缓入缓出，缺省匀速；曲线设在一个关键帧上，作用于它到下一个关键帧之间这一段；在时间轴工具栏的「运动曲线」下拉框设置，LookAt / 开关离散切换。对象轨道记录位置、欧拉旋转与等比缩放（旧位置键仍兼容）。LookAt 跟踪对象实际中心。
- 时间轴定位到整帧。第一关键帧之前保持第一键位置，最后关键帧之后保持最后键位置。没有键的对象保持当前姿态。
- 调整对象后要点击「打关键帧」（或开启自动打帧）才会修改轨道。已有轨道的数据在再次定位 / 播放时重新采样。
- Timeline 尾端是持续时间边界，可以作为尾帧参考截图；视频导出已实现，按 `[0, duration)` 枚举帧逐帧渲染编码（`src/videoExport.ts`，优先 WebCodecs H.264 MP4、降级 MediaRecorder），尾端边界不额外出帧。
- 缩短时长会移除超出新范围的关键帧，并收缩首尾标记。
- 景别根据包围盒启发式构图，没有面部识别或骨骼识别；ECU / CU 对非人物模型可能需要手动微调。
- 景深只保存参数、输出生成意图；不模拟真实光学散景、镜头畸变或呼吸效应。截图固定为 1920×1080，不受监看面板尺寸影响。
- Director Handoff 是模型无关的助手交接格式，不是视频模型的 API 请求。目标模型在导演台导出前选择，最终首尾帧与视频提示词由助手结合参考素材制作。

## 图片与三维片场（0.6）

左侧「添加场景图片」导入 JPG / PNG（每张 ≤20MB、最长边 ≤8192px），默认作外观参考。用途选「空间背景板」，图片就成为世界中有边界的平面，不再跟随摄影机铺满屏幕。旧项目背景也按此方式显示，需重新校准。

1. 在左侧调整背景板中心 X/Y/Z、宽高和朝向，保留原图比例时按同一比例调整宽高。
2. 点击「摄影机正对背景板」取得初始取景，再校准相机高度、焦距和图片地面与舞台地面关系。这个按钮会移动相机，自动打帧开启时会写入当前键。
3. 选中角色或道具，点「在地面放置选中对象」，再点中央自由观察视口的地面。对象落在 Y=0；锁定对象不会移动。
4. 「添加空间遮挡物」创建三维方块代理，可在对象属性修改名称、位置、旋转、代理尺寸和缩放，以表示柱子、墙体、桌子等。它是监看中可见的白模空间依据，不会自动匹配照片材质。
5. 观察右上监看，调整相机取景。中央自由观察可同时查看画外人物、摄影机和整个背景板。背景板内部仍是二维，横移无法自动恢复照片中的独立深度。
6. 校准后勾选「我已校准此简化空间」。这记录用户确认，不代表测量得到真实尺寸。修改板参数会重新标记待校准。
7. 在各时刻调整机位与角色并打关键帧，或开启自动打帧。对象位置、旋转、缩放及相机参数均可播放。深度导致的近大远小自动由透视产生，不需要改变人物缩放。

「实时空间反馈」显示人物画内/画外、沿镜头方向的纵深与包围盒投影高度；高度可能超过 100%，不等同于可见像素面积或自动景别识别。遮挡候选采用包围盒中心射线，最终实际遮挡由三维渲染决定。几何体材质透明或轮廓有空隙时，候选不能当作完整遮挡结论。

背景板覆盖检查用摄影机四角和中心射线；缺少覆盖会提示，背景不会自动扩展。交接包按 24fps 检查整个首尾区间，输出越界时间段。即使背景覆盖完整，也不证明单图中未见的建筑侧面已经获得参考。

导出包包含首尾图、区间四分点的三张中间图（`motion-1/2/3.png`）、图片时刻表、场景原图、空间采样、运动描述、投影变化和越界记录。中间图不是视频，也不保证捕获短暂事件；完整轨道在项目 JSON 中。人物/物体空间关系每 0.5 秒及关键帧采样，提示词区分固定机位、推进/后退、横向/升降、朝向变化和变焦。

图片原图内嵌于项目 JSON；复制镜头保留图片绑定，移除仅影响当前镜头。旧项目没有背景板参数时采用默认尺寸，需校准后保存。

新增模块：`sceneImages.ts` 图片读取与纹理缓存；`SceneImagesPanel.tsx` 场景图片/背景板校准；`spatial.ts` 空间反馈与时间段检查；`SpatialMonitor.tsx` 实时反馈。

### 本轮验收

打开 `examples/spatial-audit.xbdirector.json`：0–2 秒人物走远，2–4 秒摄影机向左转。

- 浏览器实测 A 的投影高度从 53.6% 降至 26.4%，人物缩放保持 1。
- 4 秒时两人仍在中央片场，右上监看中已出画，同时显示背景越界。
- 实际下载的 `verification/spatial-handoff.zip` 包含五张 1920×1080 构图图、场景原图与空间记录，越界区间为 2.375–4 秒。
- 自动测试覆盖透视缩小、背景板固定/转向越界、画外对象不隐藏、对象完整变换关键帧。

### 角色姿态

内置的占位人是一套带关节的简单骨架（躯干、头、两臂、两腿）。选中角色后，在「对象属性」里的「姿态」下拉框可选 11 种：站立、行走、奔跑、回眸、倚靠、坐下、伸展身体、手持物品、挥手、蹲下、跳跃。

- 姿态只为构图和站位服务，表示“这个人大致在做什么”，不代表最终动作细节。交接包的「素材职责」里会写明占位姿态。
- 换姿态会同时更新角色的包围盒（坐下、蹲下变矮，举手变高），自动构图和空间检查按新尺寸算。站立沿用原来的尺寸，旧项目不变。
- 姿态是角色的固定属性，整个镜头不变；导入的外部模型没有姿态。
- 姿态编号与提示词导演台的「人物动作」取值一致，「送到提示词导演台」时会把第一个可见角色的姿态一起带过去。
- 定义在 `src/poses.ts`，改角度或加姿态都在那里；总览图见 `docs/screens/姿态总览.png`。

自动识别图片地面/消失点、深度重建、图片分层和遮挡掩膜均未实现。目前空间依据由用户校准的背景板、地面和代理物体提供，不宣称自动理解单张图片的真实三维结构。角色只有静态姿态预设（见下），没有骨骼动画，姿态也不能打关键帧；视频模型不走官方 API，只能经监看中心的 Key 池代写提示词。

## 0.7 导出一致性修复

导出默认截止至最后有效关键帧。3 秒运动不再默认补成 8 秒；无运动轨道时保留所选范围。需要静止停留时，在编译器选择手动首尾范围，或显式添加末尾保持键。所有 TXT / JSON / ZIP 使用统一范围，中间图取范围内四分点并对齐 24fps。

截图直接将指定时刻的相机和所有对象位置、旋转、尺寸写入渲染场景后统一渲染，不再依靠等待两帧推测界面已经更新。导出后恢复当前预览对象状态。

默认固定对象第一个尺寸键，避免将补偿透视的手动缩放变成身体膨胀；可以明确勾选允许尺寸动画。导出项目记录处理后的状态，source-project.xbdirector.json 保留原始操作，export-review.json 列出原始尺寸变化和覆盖检查。

video-prompt.zh.txt 是独立中文视频提示词草稿，说明模型、设计时长、素材职责、连续镜头变化和不变量。背景越界、白模外观未定义等问题单列，不包装成已完成的最终生成提示词。仍需结合角色外观参考制作最终首尾图，实际平台时长/参考槽位按入口适配。

## 0.8 空间校准、越界穿帮、落地支撑与提示词可用性

针对单图背景板与多表面调度的核心痛点，本版完成四大升级：

1. **图片空间校准**：背景板参数增加 `pitch`（俯仰角）与 `horizonRatio`（地平线比率 0–100%）。提供「底边贴地」（背景板底边对齐 $Y=0$）与「地平线对齐机位」（图片视觉地平线对齐当前摄影机高度 $Y_{cam}$）快捷计算，解决地平脱节与视觉悬空。
2. **背景越界穿帮处理**：`boardCoverage` 实现方向性越界检测（`overflow: {left, right, top, bottom}`）。监看视口四向实时呈现半透明穿帮边缘 HUD 与越界指示；时间轴轨道直观渲染斑马纹越界时间带。
3. **精准落地与多表面支撑**：重构贴地算法 `groundedPositionY`，按世界包围盒底面对齐。不仅支持世界地面网格吸附，还支持点击场景内任意道具（平台、桌面、台阶）表面将角色精准放置其上，无穿模无悬空；对象属性面板增加「脚底贴齐地面 (Y=0)」一键快捷按钮。
4. **提示词可用性升级**：新增宏观运镜总结提炼算法（`macroCameraMovement`），将 0.5 秒切片聚合为宏观机位运镜（Dolly/Truck/Pedestal/Pan/Tilt）与主体构图演变；输出可以直接复制给 Seedance 2.5 和 Gemini Omni 1.1 Flash 的纯净投递提示词（含槽位映射与物理不变量），编译器新增「一键复制纯净提示词」按钮，与审计诊断报告清晰隔离。
