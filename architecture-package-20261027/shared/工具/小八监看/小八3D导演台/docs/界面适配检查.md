## 二、每条问题对应的 CSS 规则和修改建议

### A 系列（1040px 宽度）

| 问题 | 相关 CSS 规则 | 修改建议 |
|------|-------------|---------|
| A1 顶栏拥挤 | `header` 第 96–105 行（`gap: 24px; padding: 0 22px`）；`@media (max-width: 1040px)` 第 1987–1993 行（`padding: 8px 12px; gap: 10px; flex-wrap: wrap`） | 顶栏已做了 wrap 和缩小 padding/gap 的处理，但仍然偏密。建议在 1040 断点中将"片场/监看/层级"标签页（`.actions` 区域中的 tab 按钮）隐藏到汉堡菜单或折叠按钮中，减少顶栏元素数量。 |
| A2 项目名截断 | `.project-title input` 第 139–143 行（`width: 150px`）；`@media (max-width: 1040px)` 第 2001–2004 行（`width: 100px`） | 100px 对中文项目名太窄。建议改为 `min-width: 80px; flex: 0 1 auto;` 让输入框根据可用空间弹性伸缩，或者增加 `text-overflow: ellipsis` 提示有截断。 |
| A3 左侧面板不可见 | `@media (max-width: 1040px)` 第 2052–2054 行（`.workspace > aside.hierarchy { display: none }`） | 这是设计意图（单面板模式切换），但需确保 `.responsive-pane-switcher`（第 2020–2043 行）的切换按钮清晰可见且易于发现。建议为切换按钮增加更醒目的样式（比如更大的字号或加一个面板图标）。 |
| A4 右侧面板不可见 | `@media (max-width: 1040px)` 第 2060–2063 行（`.workspace > aside.inspector { display: none }`） | 同 A3。需要确认切换按钮能引导用户切到监看/检查器面板。 |
| A5 时间轴工具栏按钮密集 | `.timeline-toolbar` 第 1177–1182 行（`flex-wrap: wrap; padding: 6px 12px`） | 工具栏已设置了 `flex-wrap: wrap`，理论上会自动折行。建议在 1040 断点追加规则，将"自动打帧""运动曲线"等次要控件折叠到二级菜单中，只保留最核心的播放/时间码/时长控件。 |
| A6 设首帧/设尾帧等按钮消失 | 看不清是被 wrap 折行到下一行、还是被溢出隐藏了。`.timeline-toolbar` 没有 `overflow: hidden`，应该是折行了但第二行可能在视口之外。 | 建议在 1040 断点为 `.timeline-toolbar > div` 增加 `flex-wrap: wrap`，并确保各子组件有合适的 `min-width` 防止被挤压变形。 |
| A7 视口面积偏小 | `.timeline` 第 1196–1198 行（`height: 250px`，覆盖了原本第 767 行的 `height: 214px`） | 在小窗口下时间轴仍占 250px 过多。建议在 1040 断点里把 `.timeline` 高度降为 `160px` 或使用 `max-height: 30vh` 限制占比，把更多空间留给 3D 视口。 |
| A8 底部状态栏文字紧凑 | `footer` 第 904–931 行 | 不算严重，文字未被截断。当前 `text-overflow: ellipsis` 处理得当。 |

### B 系列（1280px 宽度）

| 问题 | 相关 CSS 规则 | 修改建议 |

| 问题 | 相关 CSS 规则 | 修改建议 |
|------|-------------|---------|

## 三、各宽度下最影响使用的 3 个问题（按严重程度排序）

### 1040px

| 排名 | 问题 | 理由 |
|------|------|------|
| 🥇 | A3/A4 — 左侧层级和右侧检查器完全不可见 | 用户无法查看/编辑场景层级和摄影机属性，功能严重受限。如果面板切换按钮不够醒目，用户可能不知道怎么切到这些面板。 |
| 🥈 | A7 — 3D 视口面积过小 | 视口是核心操作区域，面积太小直接影响场景搭建和镜头调整的效率。 |
| 🥉 | A2 — 项目名被截断 | 输入框只有 100px，中文项目名很容易看不全，影响辨识。 |

### 1280px

| 排名 | 问题 | 理由 |
|------|------|------|
| 🥇 | B1 — 检查器属性面板底部被截断 | 焦距、FOV 等关键摄影机参数看不到，用户需要手动滚动才能访问，严重影响调参效率。 |
| 🥈 | B4 — 左侧面板文字拥挤 | 222px 宽的面板在显示中文长文本时频繁换行，视觉混乱。 |
| 🥉 | B3 — 时间轴工具栏元素密集 | 虽然没有重叠，但按钮间距很小，触控或快速操作容易误触。 |

## 四、对照设计稿（新风格）分析

> 参考截图：`设计稿-新风格-1440.png`

### 设计稿与现状的主要视觉差异

| 对比项 | 现状 | 新风格设计稿 |
|--------|------|-------------|
| 整体色调 | 暗灰色系（`#111318` 背景） | 更深的暗蓝色系，卡片和面板边界有更明显的蓝色调 |
| 面板边框 | 颜色偏淡（`#2c3038`） | 边框更明显，有浅蓝色的微光感 |
| 按钮样式 | 扁平风格，金色高亮 | 保持类似的金色强调色，但按钮外观更精致、有更明显的圆角和渐变 |
| 左侧面板 | 纯树形列表 | 结构类似，但视觉层次感更强 |
| 右侧面板 | 较紧凑 | 间距更宽松 |

### 新风格下哪些问题会变好

| 问题 | 理由 |
|------|------|
| B4 左侧面板文字拥挤 | 设计稿中左侧面板的文字间距更大、层次更清晰，视觉上不那么拥挤。如果新风格增加了面板内 padding 和行间距，这个问题会缓解。 |
| B6 空间反馈文字阅读吃力 | 设计稿中信息面板的文字对比度更高、字体渲染看起来更清晰。 |
| 整体视觉质感 | 新风格的深色主题更统一，面板边界更明显，有助于区分各功能区域。 |

### 新风格下哪些问题可能变得更糟

| 问题 | 理由 |
|------|------|
| B1/C2 检查器属性被垂直截断 | 设计稿中右侧面板的间距看起来更宽松（更多的 padding/margin），这意味着在相同窗口高度下，能展示的属性字段行数更少，截断问题可能更严重。 |
| A3/A4 小窗口下面板不可见 | 设计稿只展示了 1440 宽度的效果。新风格如果没有同步优化小窗口断点的适配方案（responsive-pane-switcher 的可发现性），1040 下的问题仍然存在甚至更糟——因为新风格更依赖三栏同时可见的布局来呈现完整功能。 |
| A7 时间轴占用高度 | 设计稿中时间轴区域的视觉份量未见明显缩减。如果新风格增加了工具栏高度或时间轴区域的 padding，视口被压缩的问题会恶化。 |
