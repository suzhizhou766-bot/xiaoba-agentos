# Seedance 2.5 · 导演台提示词与使用指南

核验日期：2026-09-16；资料版本：2026-09-16.1

素材职责 + 空间关系 + 分段时间轴 + 运镜 + 声音 + 不变量。

## 官方资料核验摘要

- 模型页公布单段最长 30 秒、可延长两次，并列出白模控制等能力。能力上限不等同于任意平台都提供同样参数。来源：Seed 模型页。
- 官方发布案例把白模运动/调度和最终外观素材分配不同职责；示例使用 @Image、@Video 等引用及时间区间组织镜头。即梦网页入口为视频生成后选择 Seedance 2.5。来源：Seed 发布页。

## 本项目推荐操作步骤

1. 在导演台选 Seedance 2.5；时间轴保留完整运镜、角色位置与首尾构图。
2. 助手先制作最终首尾图，再把几何轨迹翻译成中文镜头语言与阶段状态。
3. 用户在即梦或实际使用的入口选择该模型和对应的首尾帧/参考模式，绑定最终素材。
4. 将提示词中的素材名称替换成该平台实际生成的引用标记；未上传的参考视频不要写入提示词。
5. 选择平台允许的时长和画幅，检查音频要求后生成；超过单段能力时由助手给出分段方案。

## 交付语言

以中文制作稿和中文投递提示词为主；按用户平台需要再提供英文。

## 本项目归纳：保留此前导演写作框架

素材各自负责什么 → 人物与建筑空间关系 → 按时间段描述动作 → 摄影机路径 → 声音 → 不变量。此前对话中的经验性写法作为工作方法保留，参数和上限仅采用本轮核验的官方资料。

## 本项目模板：首尾帧与时间轴

首图锁定初始站位、机位与画面边界，尾图锁定结束构图。每段说明开始状态、主体动作、摄影机和结束状态；下一段接续上一段。镜头从人物正前方横移到侧前方时，应写出路径与最终相对角度，不能只写“向左”。

## 本项目模板：素材隔离

角色参考只负责身份、服装、比例；场景参考负责建筑、材质和光线；运镜参考只负责机位、速度与调度。若后续补充白模视频，要显式说明不继承占位材质。当前导演台只导出静帧与数据，不能冒充已有白模视频。

## 本项目模板：声音与连续性

对白、环境声与音乐分别说明；有对白时标清说话者。写清可改变的是视角和动作，保持的是角色身份、人数、道具归属、建筑结构与空间轴线。精确字幕交给后期，不靠形容词堆叠保证。

## 导演台实践：先把三维数据翻译成可见结果

世界坐标供助手重建路径，不应直接堆进视频提示词。把坐标变化解释成主体位于画面左/中/右、景别如何变化、前后景如何遮挡。机位向目标靠近是推进；镜头焦距变化才是变焦，不能混为一谈。方向同时说明是画面方向还是角色自身方向。时间线不是对生成模型的逐帧约束。

## 导演台实践：明确素材职责

first-frame-blocking.png 与 last-frame-blocking.png 只控制取景和站位。由助手根据角色/建筑/风格参考制作 final-first.png 与 final-last.png，再交给视频平台。人物占位模型不代表最终服装、肤色、性别或画风；当前包不包含运动视频，不要声称已有白模参考视频。

## 导演台实践：首尾图制作约束

两张最终图使用同一组角色与场景参考，统一人物数量、服装、道具归属、建筑几何、材质和光照方向。分别匹配首尾投影与画面裁切。移动机位可以改变透视与可见区域，不应为了凑尾帧重排物体。先核对首尾图是否能由一段连续空间运动连接。

## 导演台实践：排错顺序

先查参考槽位是否用错，再查动作和镜头描述是否矛盾，再检查首尾空间是否连续。身份漂移时具体列出要保持的外观；左右互换时补充画面坐标关系；运镜跳跃时减少同一时段的运动指令。一次只改一类问题；这些是本项目的制作建议，不是官方成功率承诺。

## 导演台实践：提交与验收

用户在所选平台打开对应视频模型，把最终图像绑定到首尾槽位或明确指定图片职责，再粘贴成品提示词。画幅、可选时长和画质以该入口为准。验收人物身份、数量、建筑、动作方向、运镜连续性、结尾构图和声音。精确商标/字幕可在后期合成。

## 原创制作模板

【任务】依据最终首尾图生成{时长}秒的连续镜头。
【素材职责】{平台内首图引用}=起始构图；{尾图引用}=结束构图；{角色/场景参考}=外观与空间依据。只列已经实际上传的素材。
【空间关系】{人物相对位置、朝向、前后景}。
【时间轴】0–{节点1}s：{主体动作、镜头路径、阶段结束状态}；接续至{总时长}s：{最终构图}。
【摄影机】{起始机位、运动方向、景别变化、结束机位}。
【声音】{环境声、音乐、对白要求}。
【不变量】{人物身份、服装、道具归属、建筑、光照方向}。

## 交接给助手

用户已选择 Seedance 2.5，无需再询问模型。按素材职责、空间关系、时间轴、摄影机、声音和不变量组织中文成品提示词，并制作最终首尾图。素材引用以实际平台槽位为准；不能凭空补入参考视频或未经核验的 API 参数。
