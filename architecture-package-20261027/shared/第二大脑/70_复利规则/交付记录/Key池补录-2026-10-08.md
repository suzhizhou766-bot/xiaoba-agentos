## 使用方式

- 开：代理随监看中心启停；页面入口 http://127.0.0.1:8799/ 的「Key 池」标签。
- 客户端 API 地址填 http://127.0.0.1:8780（要求带 /v1 的填 .../v1），Key 填页面上复制的合并 Key；关掉监看中心后合并 Key 不能用。
- 端口可在 monitor.json 里用 {"keypool": {"port": 8780}} 覆盖；对比测速用 tools/keypool_speedtest.py --model <模型名>（README.md）。
