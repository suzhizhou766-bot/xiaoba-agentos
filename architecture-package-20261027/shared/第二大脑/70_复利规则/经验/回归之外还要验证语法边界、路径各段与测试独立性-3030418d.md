# 回归之外还要验证语法边界、路径各段与测试独立性

2026-10-10，AgentOS v1.5.2 第三轮主力完整离线回归574项通过，测试输入未漂移；新增独立探针仍发现两个代码缺口和一类测试设计问题。该记录仅是候选实现核查，不是正式发布验收。

标题围栏识别把反引号信息串的限制错误套给波浪线围栏，导致合法波浪线代码中的H1成为经验标题。修复应依据具体语法规范，增加合法信息串、未闭合与假任务节反例，不笼统放宽缩进。依据 CommonMark 0.31.2 §4.5：https://spec.commonmark.org/0.31.2/#fenced-code-blocks 。

实体根只检查末级软链接，会漏掉alias/nested中上级alias软链接。路径安全应验证未经resolve的原始路径各段；用于正常夹具的物理根可以在构造夹具时确定，不能全局忽略平台或任意软链。正式默认核验与显式staging验收边界应保持。

永久单元测试不应断言“正式实体尚未安装”。安装前现场状态是部署阶段证据，测试必须用临时实体模拟缺失/存在/漂移，避免上线完成反而使回归失败，也不能靠skip掩盖正反例。

辅助报告中可应用diff仍需复验。本次报告diff的hunk计数错误，patch明确失败；主力从不可变v1.5.1和初始补丁重建历史fixture，校验原哈希后生成真实差异，实际应用逐字节匹配候选。不能据“diff自动生成”自述代替可应用性验证，也不能把旧差异当成后续修正的最终差异。

贡献记录按实际行为区分：本轮Q3由Flash实现、Max发现并发后只读复核，不计两份实现。有限评分G3 Gemini4/5、Q3 Flash实现3/5、Q3 Max复核4/5、D3 DeepSeek3/5；F3尚无报告，不评分。不推断通用模型能力排名。
