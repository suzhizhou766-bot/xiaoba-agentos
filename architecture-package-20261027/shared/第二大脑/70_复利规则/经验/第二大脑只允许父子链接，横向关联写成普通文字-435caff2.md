# 第二大脑只允许父子链接，横向关联写成普通文字

## 规则

向第二大脑写入或修改笔记时，WikiLink（双方括号链接）只能用于一种情况：
父笔记链接到它的直接子笔记，并且每篇子笔记只被它的父笔记链接一次。

除此之外的关联一律写成普通文字，不加双方括号。包括：
- "关联方法""关联资产""参见"这类横向引用；
- 子笔记指回父笔记或兄弟笔记；
- 正文里顺手提到另一篇笔记。

写法示例：
- 错：关联方法：`[` `[30_方法与知识/提示词与摄影方法]` `]`（连写的双方括号）
- 对：关联方法：30_方法与知识/提示词与摄影方法

## 为什么

索引校验（build_knowlp_index.py）把第二大脑当作一棵严格的树：
链接总数必须等于笔记数减 1，且每条链接都是父到子。
多出任何一条链接，校验就失败，裁决中心所有裁决都会停在"第二大脑同步待重试"，
点"重试同步"也无效，直到多余链接被去掉。

## 写入后的自查

新增或修改笔记后，确认两件事：
1. 新笔记在它的父笔记里出现且只出现一次双方括号链接；
2. 除此之外，本次改动没有新增任何双方括号链接。

## 适用范围

所有会写第二大脑的 Agent（Antigravity、Codex、Claude Code、DeepSeek Harness 等），
包括更新技能卡、方法卡、资产索引时的"顺手关联"。
