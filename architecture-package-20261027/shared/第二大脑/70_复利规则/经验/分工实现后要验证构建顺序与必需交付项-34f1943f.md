# 分工实现后要验证构建顺序与必需交付项

2026-10-10，AgentOS v1.5.2 第二轮四模型实现经主力完整离线回归：506 项通过，测试输入未漂移；正式独立审核、构包与切换尚未执行。这是候选实现记录，不是版本已发布证据。

可复用教训：单元测试通过仍可能漏掉跨卡顺序。新增共享实体应允许候选验收使用明确 staging 根，索引 metadata 始终写正式路径，正式默认校验不能降级；不能为让构包成功提前安装正式实体。模板校验必须检查必需项集合、唯一身份与路径，而不只检查每项字段类型，否则合法剩余条目会掩盖缺项。退役执行入口以后也要清理配置默认/校验契约；范围之外的遗留应如实报告交接，不越权修改。

本轮有限评分：G2 Gemini 4/5（八标记及预算接口回归通过，运行与构包仍为两份相同常量）；F2 Qwen Flash 4/5（固定正文/metadata 与冻结证据一致，完整链路尚待）；D2 DeepSeek 3/5（局部功能通过，但 staging 构包顺序和模板缺项约束漏项）；Q2 Qwen Max 4/5（冻结及健康边界通过，配置遗留明确停止交接）。分数只用于这四个具体任务，不能推断通用能力排名。

核查应读磁盘、冻结输入哈希，复现跨步骤缺口，再按互斥文件责任发下一轮任务卡。用户人工转交，宿主不自动派发或变更模型路由。阶段测试数必须绑定当时输入，旧 SOURCE_MANIFEST 失效时不得继续称它代表新源码。

验收要点：staging/默认正式校验边界分别有正反例；模板缺项/重复/额外/身份变化均失败；退役配置空动作通过、旧动作拒绝；完整范围定稿后再统一版本号/清单并执行 AGY+DSH 独立审核。经验候选仅由用户两阶段裁决发布。
