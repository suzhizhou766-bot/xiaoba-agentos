# 发版前实地盘点，接入后用任务说法实测

来源：2026-10-10，v1.5.1 上线后用户指出“小八审美手册”没有进这一版。宿主 Claude Code 整理。

## 事实

- 审美手册由另一个 Agent 建在 `私人助理/审美提升/`，有手册、索引、日报和样本，但没有登记进 `AGENTS.md` 模块清单、技能索引、发布生成的第二大脑树和 `registry.json`。
- 负责发版的 Agent 只按工作区登记页的清单定范围。那张清单上没有审美手册，于是没有做，也没有问用户。
- 补入口笔记之后实测：带“审美”二字的检索能命中；“做一个好看的网页”“帮我调色”这类任务原话查不到；技能匹配对“审美”返回空。
- 这两件事处理完后没有记踩坑，是用户追问才补记的。

## 可复用的做法

1. 发版的范围有两个来源：待办清单，和一次实地盘点。盘点要看私人助理顶层目录、工具、技能实体文件夹、各 Agent 的私有技能目录、上一版之后新发布的经验笔记。查到的东西逐项核对四处登记，清单交用户决定。流程写在第二大脑 `40_工作流/AgentOS发版流程.md`。
2. “写进去了”和“别的 Agent 找得到”是两回事。第二大脑检索按字面匹配、最多 6 条；按任务找能力要靠技能索引里的触发词。接入一样东西后，用名字、用特征词、用任务原话各测一遍，把查不到的如实写出来。
3. 每天在改的文件不要放进带哈希绑定的索引；绑定一份稳定的指路文件。
4. 要让别的 Agent 一定看到的规则，放在它们必读的地方（`AGENTS.md`、工作区登记页、`40_工作流/`），不依赖检索。
5. 用户明确指出问题时当场记录：踩坑、经验候选、偏好，不等交付。只记在自己的记忆里不算。

## 没有验证的

- 没有让一个全新的 Agent 从零走一遍入口来验证它会不会读到这些规则。
- “版本升级”“好看 网页”两个查询笔记里有字却没命中，原因没有查清。
