# 做声音先读全 bgm 技能：决策卡、分层验收、五件交付

适用场景：任何带配乐、音效、混音的任务，包括用户指定只用小八音效库的情况。

做法：
1. 动手前跑 skill-match，读 skills/bgm/SKILL.md 全文，以及它为当前模式指定的 references（诊断“太平、太弱”读 composition_framework.md 和 audio_acceptance.md）。
2. 事前写「小八 BGM 决策」卡：用途、能量曲线、段落、BPM、低音职责。
3. 验收分技术、结构、音乐、混音四层分别报告，给出 PASS / PASS WITH FIXES / REBUILD；听不到声音的层要写明待用户判断。
4. 交付五个文件：BGM 单轨、SFX 单轨、预混总轨（48k WAV）、音乐结构与混音验收报告、音效时间轴 CSV。
5. 用户说“用音效库”只改变生成器路线（不用 ElevenLabs Music），技能的验收和交付要求照样适用。

证据：2026-10-14 用户问做《小八AgentOS成长历程》声音时是否读过 bgm 技能；事实是只读了前 80 行，v004 事后补齐了五个文件（AI视频管线/05_输出/交付/小八AgentOS成长历程/v004/），分轨相加与总混音残差 -145.9 dB。
