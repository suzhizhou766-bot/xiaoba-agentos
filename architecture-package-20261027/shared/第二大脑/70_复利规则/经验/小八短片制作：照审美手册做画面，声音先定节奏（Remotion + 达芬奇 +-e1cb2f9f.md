# 小八短片制作：照审美手册做画面，声音先定节奏（Remotion + 达芬奇 + 音效库）

适用场景：用 Remotion 做画面、达芬奇剪辑混音、小八音效库配声，做 1 分钟左右的说明类或回顾类短片。

做法：
1. 动手前读审美手册 taste 卡和相关样本卡。2026-10-14 用户比较两条小八短片后认为照手册做的那条更好。
2. 声音先定节奏：选配乐时先测速度和段落（ffmpeg ebur128、频段能量），把换场和换字放在重拍上；每次换场配 whoosh 或上升音；至少安排一次“抽走低音再落地”。参考片（Opus 5.5《反直觉·06》）的关键换字与低音重拍偏差不到 0.06 秒，段落之间低频差约 10 dB，响度 -14.7 LUFS。
3. 一份帧号时间表同时驱动画面和声音；Remotion 出 ProRes HQ 无声母版（--color-space=bt709），达芬奇用脚本建独立工程、按时间表铺音轨、设音量淡入淡出、出 H.264。
4. 先渲染到工作目录，测规格、响度、逐半秒峰值，再进交付目录；交付目录版本不可覆盖。
5. 工具细节和坑：Remotion 大字体 delayRender 要 120 秒；达芬奇导入 MP3 可能静默失败，先转 WAV；同轨重叠的片段会被顺延，放完读回位置；AppendToTimeline 的 endFrame 不含末帧；比颜色用区域平均，不用单个像素。

证据：两条成片与交付文件在 AI视频管线/05_输出/交付/小八AgentOS成长历程/v003 与 小八记得/v001；打法 Playbook/打法/视频短片_Remotion达芬奇与音效_2026-10-14.md；参考片拆解 审美提升/样本与拆解/2026-10-14_Opus5.5参考片/样本卡.md。声音结论来自测量，制作者听不到声音。
