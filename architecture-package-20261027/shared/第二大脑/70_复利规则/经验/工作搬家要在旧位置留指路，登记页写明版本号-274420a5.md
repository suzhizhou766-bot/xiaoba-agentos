# 工作搬家要在旧位置留指路，登记页写明版本号

工作位置搬家或登记进行中的工作时，要让“从旧位置、按版本号”找的 Agent 也能找到。

事实（2026-10-10）：Codex 会话的工作目录是 小八AgentOS，用户问 v1.5.2 的预发布内容，它只在该目录按“1.5.2”搜文件名和正文，答“没找到”。实际内容在 私人助理/工作区/README.md 的“下一版待办”一节；该页当时没有“1.5.2”“预发布”字样，小八AgentOS/AGENTS.md 也没有指向通用入口。

做法：
1. 候选目录、待办这类东西换了存放位置，就在旧位置（小八AgentOS/work）和各 Agent 会当作工作目录的项目根入口文件里留一段指路。
2. 登记页的标题和正文写上别人会拿来搜的版本号和口头叫法（例如 v1.5.2、预发布），不只写“下一版”。
3. 还没有候选目录或预发布包时，在登记页明说“目前只有待办表”，免得被当成读不到。
4. 任何 Agent 在说“没找到”之前先做 memory-retrieve 并读 工作区/README.md。

验证：修复后在 小八AgentOS 内原样重跑当时的搜索命令，命中 3 行；doctor 通过。Codex 新会话的实际表现未验证。
