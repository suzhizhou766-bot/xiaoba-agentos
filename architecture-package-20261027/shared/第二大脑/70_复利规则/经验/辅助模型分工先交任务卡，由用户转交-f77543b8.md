# 辅助模型分工先交任务卡，由用户转交

来源：2026-10-10 用户在 v1.5.2 发布规划中明确纠正“生成任务卡，发给我，我转交给他们”。

问题：宿主把“根据四个辅助模型特性分工”误扩展为寻找自动调用入口，还询问 Qwen 的调用方式。读取模型能力档案不等于获得自动调模型或改模型路由的授权。

做法：
1. 先区分辅助任务的人工转交与正式 AgentOS AGY/DSH 独立审核。用户选择人工转交时，宿主提供任务卡，不自动派发、不改桌面模型和上游。
2. 卡片写明目标、实际材料路径、允许文件、限制、验收条件、停止条件和回执。涉及共享源码的设计先独立提交报告；实现阶段再划独占文件范围，避免并发覆盖。
3. 模型特性必须有依据，有限本机实测优先。档案中的公开资料倾向只作为推断，不能当作当前路由或普遍能力保证。
4. 主力核查实际文件和测试证据后才认定完成，任务卡准备好不代表模型已执行；辅助预审不替代正式双后台验收。

验证：已生成 DeepSeek V4.1 Flash、Qwen 3.8 Flash、Gemini 3.8 Flash (High)、Qwen 3.8 Max 四张首轮只读设计卡。卡片产物互不重叠，用户转交，主力等待报告。未自动派发四模型，未改客户端模型选择；未收到报告，实际模型任务结果未验证。

证据：私人助理/工作区/小八AgentOS-v1.5.2/RELEASE_PLAN.md、tasks/；踩坑及偏好已写 Playbook。本条仍需用户裁决，不直接写长期经验。
