# 故障自愈与任务恢复

session-start 在本地doctor通过后执行AGY+DSH真实健康标记探针，不能用缓存健康代替。两侧合格才接单。外部额度/429/503/断连/超时报告并有界退避，不反复改代码或切账号；认证失败是不可重试的终态，只报告。

- 同伴自动诊断与自动修复、Headroom自动重启退役；AGY+DSH的正常分工、独立审核与确定性裁判继续保留，两侧都要合格。
- 单侧故障保存输出、执行回执与冻结快照及各层哈希。新鲜真实健康探针只更新健康结果，不自动改变冻结状态，也不解冻任务。
- 恢复由用户带 --freeze-hash 显式执行，旧的 resume_ready 记录仍可显式恢复；两种方式都只补跑失败侧，哈希、回执与环境复核不得省略。
- 单轮输出预算耗尽按任务级失败处理：worker不自动原样重发（重发只会再撞同一个上限），用户手动恢复时返回拆分任务的提醒；这与外部额度、限流、超时可有界退避重试是两件事。真实认证、网络、容量故障仍阻断后台，健康由用户重新“上班”时的真实探针更新，不自动补探。
- 历史修复记录与审计事件保留但不再参加调度；不删除历史，也不因此新增备份。

发布绑定失配立即停止。
