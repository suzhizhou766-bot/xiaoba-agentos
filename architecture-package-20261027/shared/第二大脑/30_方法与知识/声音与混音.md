# 声音与混音

- 先定义叙事功能、能量曲线、动机、低音、和声、乐句、织体和对白空间，再写生成提示词。
- BGM、SFX、旁白和对白始终分轨；音效只服务动作点、转场点、信息点、空间点或品牌点。
- 正式音频默认 WAV PCM、48 kHz、双声道、16-bit 或更高；技术、结构、音乐和混音分层验收。
- 功能、动机、结构或声源路线错误时重建；只有接缝、增益、频段和短淡化问题时局部修补。
