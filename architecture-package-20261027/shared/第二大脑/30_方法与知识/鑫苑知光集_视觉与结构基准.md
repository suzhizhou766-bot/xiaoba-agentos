# 鑫苑知光集_视觉与结构基准

- **合规总则**：建筑外立面必须 100% 忠实于报规总图与各栋真实户型设计，严禁臆造“跑马阳台”或违规对称化。
- **三大核心栋型**：
  - 栋型 A（边套错层挑空大平层塔楼）：强非对称性，一侧错层大进深空中露台（纯白陶板 + 暖木纹铝板吊顶），一侧通高竖向采光幕墙凹槽。
  - 栋型 B（标准对称高层塔楼）：垂直中轴线脚划分对称开间，特定上部楼层转角悬挑大露台（暖木纹铝板吊顶）。
  - 栋型 C（低密多单元板式洋房）：大横向面宽，通长白色挑檐贯通，顶层玻璃采光花房顶冠。
- **PBR 材质规范**：
  - 挑檐/白色线条：纯白/象牙白哑光陶板（Terracotta）；
  - 主墙/立柱：深灰氟碳喷涂铝板；
  - 露台栏板：大圆弧转角单面透光隐私暗色玻璃（正面深黑具私密性，侧面镜像反光）；
  - 露台生态：四代宅错落弧形大露台，**露台上严禁出现任何红枫树**。
- **光影与色彩法则**：
  - 纯净深湛蓝天幕；
  - 浅香槟暖金侧光 + 蓝天冷灰阴影双色温冷暖对撞，杜绝任何全局发黄泛橙的低质滤镜；
  - 真实质感草坪真草皮，健康生动深翠绿树冠，红枫（Acer palmatum）仅限地面水系。
- **核心工艺节点**：
  - 琴台背景墙：普通天然浅色米白/暖灰石材饰面板（严禁木纹，严禁拉花大理石）；
  - 悬挑观景台：密集横向米白细陶板条 + 立向青铜金属 LOGO + 树影投射（尺度克制，严格水平，严禁特写放大变形）；
  - 儿童乐园：实木几何木屋箱体 + 镜面不锈钢圆角金属包边 + 水磨石看台与地脚灯（严禁多余玻璃护栏，纯净无人物）。
