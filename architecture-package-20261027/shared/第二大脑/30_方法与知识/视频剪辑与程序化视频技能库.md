# 视频剪辑与程序化视频技能库

## 定位与证据边界

本模块是当前宿主机的视频技能路由知识，不替代正式 Skill 正文，也不把宿主级 Skill 自动升级为小八 AgentOS 正式能力条目。Skill 正文以本机安装目录为权威；调用前仍须读取对应 `SKILL.md`。小八 AgentOS 的正式可调用 Skill 仍由其哈希绑定的 `skills/index.json` 决定，本模块通过第二大脑与 KnowLP 提供检索、选路和交接依据。

统一 Skill 根目录：`/Users/suzhizhou/.agents/skills`。

2026-09-12 本机核验：下列 30 个 `SKILL.md` 入口均为真实文件；Remotion 12 个 Skills 的 frontmatter 版本均为 `4.0.523`。FFmpeg 9.0.1、OpenAI Whisper 20240930、MLX Whisper 0.4.3、MoviePy 2.2.1、PyTorch 2.8.0 可从当前 Python 3.9 环境读取。`auto-editor`、`remotion`、`hyperframes` 未作为当前 Python distribution 安装，且 Auto-Editor / HyperFrames CLI 未在当前 PATH 中独立检出；因此这里只确认相关 Skill 已安装，不把 CLI 可运行性写成已验证事实。使用 `npx` 的命令可能需要项目依赖或网络下载，执行前先检查项目与授权。

## 总路由优先级

1. 小八会话先走 AgentOS Intake Router；端到端视频项目优先正式 `director`，可复现合成优先正式 `remotion`。后台双 Agent 负责独立分析与裁判，当前宿主 Codex/Claude 负责按选定 Skill 实际执行。
2. 在装有 HyperFrames 的宿主中，任何新建、编辑、动画、渲染、检查或发布视频的需求先读 `hyperframes`；用户明确选择其他框架时再转入对应框架。
3. 短且无旁白、以动效为核心：`motion-graphics`；较长、多场景、叙事或自由合成：`general-video`；单主体口播字幕且不改镜头：`embedded-captions`。
4. 明确的 Remotion 项目或用户指定 Remotion：`remotion-best-practices` 路由，再加载 `remotion-create` / `markup` / `captions` / `maps` / `render` 等专项 Skill。
5. 去静音、按响度/运动/黑帧剪切、节奏压缩：`auto-editor`；特效动作、编辑器工程导出、按语音内容剪辑分别转 `auto-editor-effects`、`auto-editor-export`、`auto-editor-transcribe`。
6. 单纯转码、裁切、压缩、混音、封装、烧录字幕或生成缩略图：使用 `ffmpeg` Skill 与本机 FFmpeg；Python 编排、批量素材生成或与数据逻辑结合时可用 MoviePy。
7. 字幕转写在 Apple Silicon 生产环境优先 MLX Whisper；官方 OpenAI Whisper 固定 CPU 兜底。只有缺能力时才使用 `find-skills`，安装前单独确认来源、版本、磁盘和安全影响。

## 底层工具（4）

### FFmpeg 9.0.1

- 来源与路径：Homebrew 构建；`/opt/homebrew/bin/ffmpeg`，Cellar 版本 `9.0.1_1`。
- 用途与场景：所有确定性媒体探测、转封装、编解码、滤镜、音频混合、字幕烧录、缩略图和最终技术 QC。
- 典型调用：先 `ffprobe` 检查，再使用 `ffmpeg`；输入音视频/图片/字幕，输出媒体、帧或分析数据。
