# 项目标准闭环

```text
需求与源文件
  → 项目决策卡与成片承诺
  → 分镜、视觉、声音和提示词路由
  → 生成、拍摄或可复现合成
  → 技术 QC、资产清单与版本说明
  → 用户验收
  → 可复用规则候选
```

原文不覆盖，正式版本不覆盖；付费、发布、删除和创意最终验收由用户决定。
