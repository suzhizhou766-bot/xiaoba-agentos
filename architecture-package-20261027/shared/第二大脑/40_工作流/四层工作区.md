# 四层工作区

1. 原始资产层：保留来源和原文件，不直接塞入通用上下文。
2. 机器索引层：保存哈希、路径、时长、格式、授权和使用状态。
3. 执行工作层：草稿、预览、缓存和中间产物只进入运行时目录。
4. 正式交付层：版本化成片、分轨、清单、QC 和用户验收记录。

长期保留的是规则、索引、技能和验收经验，不是每个临时媒体版本。
