# v1.4.0 历史版本记录

用途：仅用于追溯，不作为当前操作指令。

发布记录日期：2026-09-09

发布时说明：

v1.4.0 在 v1.3.4 的动态 CC Switch 路由上增加双 Agent 真实健康探针、故障分类、单侧成果冻结、受控互修和显式任务恢复。

用户说“上班了小八助理”后，稳定入口执行本地 `doctor`，再让 `gpt_codex` 与 `claude_code` 分别完成一次极低输出的真实推理探针。两者健康时才开放双 Agent 任务队列；一方内部 Headroom 故障时，由健康 Agent 提供只读诊断，控制平面只允许重启 AgentOS 自己创建的 Headroom 并重新探测；429、认证失效、第三方断连或慢响应只报告和退避，不修改代码或 CC Switch。

任务执行中若一方已完成、另一方故障，系统保存任务快照、成功输出哈希、执行凭单哈希和 Provider 尝试事件哈希，进入 `frozen_paused`。修复并通过真实探针后转为 `resume_ready`，用户通过 `task-resume` 显式解冻；系统复用已完成 Agent 的输出，只运行失败 Agent，并给予受限的恢复调用额度，最后重新达到双 Agent 门槛并进入裁判。
