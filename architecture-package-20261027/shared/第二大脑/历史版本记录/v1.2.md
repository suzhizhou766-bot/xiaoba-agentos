# v1.2 历史版本记录

用途：仅用于追溯，不作为当前操作指令。

发布记录日期：2026-09-06

发布时说明：

小八 AgentOS 是本地、可恢复、可审计的多智能体控制平面。它管理任务队列、并行 Agent、裁判、技能路由、价值文件目录、第二大脑检索、经验待发布和受控进化；用户是唯一规范制定者，CC Switch 是唯一上游路由权威。

后台 Codex CLI 使用独立 `CODEX_HOME`，但不能绕过 Headroom。Headroom 的 OpenAI 路径保留 CLI 传入的认证头，Anthropic 路径保留受控托管认证；`doctor` 会机器检查这两个不变量。

- SQLite 任务队列、租约恢复、指数退避、调用预算和只追加哈希事件链。
- Codex 与 Claude 只读执行；至少两个成功结果才进入确定性裁判。
- CC Switch 当前 Provider 动态解析；AgentOS 不读取 Provider API Key。
- 正式技能索引：只加载 `active`、`callable` 且文件清单哈希完全匹配的技能。
- 价值文件索引：限制允许根目录、敏感排除、内容安全和哈希准入。
- 专用 v1.2 第二大脑树：唯一根、唯一父节点、无环、无孤儿；KnowLP 只负责定位。
- 经验默认只进入私有 outbox，未经门禁不写权威记忆。
- Evaluation Plane 与 Production Loop 隔离，策略晋升必须显式批准。
