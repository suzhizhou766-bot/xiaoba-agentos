# v1.3.1 历史版本记录

用途：仅用于追溯，不作为当前操作指令。

发布记录日期：2026-09-07

发布时说明：

小八 AgentOS 是本地、可恢复、可审计的多智能体控制平面。v1.3 在原有任务队列、并行 Agent、确定性裁判、技能/知识准入与受控进化之上，增加统一会话入口路由、回答来源证明、两阶段用户裁决和可验证的经验生命周期。用户仍是唯一最终裁决者；桌面 Codex 的官方登录态与后台 CLI 流量完全分离。

claude_code（Claude CLI）       ─→ Headroom Anthropic ─→ AMD API
                                          ↑
                       CC Switch AMD Provider 记录（只读配置/凭据来源）
```

原有的两个独立 Agent 角色保持不变：`gpt_codex` 是只读 Codex CLI，`claude_code` 是只读 Claude CLI。两条链路都先经过 Headroom，再到各自固定的 AMD Provider；CC Switch 只提供已登记 Provider 的非敏感配置与受限凭据引用，不切换任何全局 Provider。后台 Codex 继续使用小八专用 `CODEX_HOME` 和 `--ignore-user-config`，不读取或改写桌面 Codex 的官方登录态。只读 Broker 只把一个允许字段交给对应子 CLI，AgentOS 主进程不记录、不输出密钥。
