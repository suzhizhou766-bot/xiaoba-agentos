# v1.1 历史版本记录

用途：仅用于追溯，不作为当前操作指令。

发布记录日期：2026-09-04

发布时说明：

小八 AgentOS 是一个可恢复、可审计的多智能体控制平面。它负责任务队列、并行执行、裁判、经验待发布和策略进化；**用户是唯一规范制定者，CC Switch 是由用户控制的模型网关和上游路由权威**。

适配器把 Codex Responses 与 Claude Messages 都送入 Headroom；Headroom 完成上下文优化后转发到 CC Switch。Provider、密钥、优先级和切换仍完全由用户在 CC Switch 中决定。Worker 在取得任务租约前验证 Headroom 与 CC Switch 均可用。

- SQLite 持久任务队列、租约恢复和指数退避；
- 多 Agent 并行执行，至少两个成功才允许裁判交付；成功结果跨重试复用，永久错误不重试；
- 每任务最多 6 次 Agent 调用，并把裁判策略固定在任务提交时的版本；
- 只追加哈希事件链；
- KnowLP 只读定位；AgentOS 对命中路径进行 vault 边界校验后回读第二大脑原文，不把索引摘要当作权威事实；
- Obsidian 经验 outbox，默认不自动发布；
- 基于成功率与延迟的独立进化循环；
- 可回滚、带运行态验收的 macOS LaunchAgent 安装。
- 独立签名的“小八 AgentOS Runner.app”，作为后台服务的专用隐私权限主体。
- Evaluation Plane：离线 deterministic replay、dataset/regression case、shadow/replay 记录与 promotion gate；评估不会写入生产 `agent_runs`、正式任务或 memory outbox。
- 任务提交保存不可变 execution snapshot（prompt、KnowLP context/hash、Agent/config/strategy 元数据）；旧数据库采用 additive SQLite migration 兼容升级。
- Evolution 只生成 candidate/proposal；必须通过回归门禁并由 `promote` 显式批准。`rollback` 原子切换策略并写审计事件。
- 本地 Unix socket Bridge（目录 0700、socket 0600）提供受限 JSON envelope 查询/提交入口，不执行 shell、路径操作或隐式自动触发。
- 跨进程单写者数据库迁移、显式 schema 版本，以及可由 `status` 核验的 Worker 代码指纹；健康检查本身不迁移生产库。
