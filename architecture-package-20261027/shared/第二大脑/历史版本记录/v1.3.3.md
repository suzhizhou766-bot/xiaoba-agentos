# v1.3.3 历史版本记录

用途：仅用于追溯，不作为当前操作指令。

发布记录日期：2026-09-08

发布时说明：

两个后台 Agent 自动读取 CC Switch 对应 CLI 的 Provider 列表，按「福利 gpt → GPT plus → GPT pro」优先级调用。每个选定上游使用独立本机 Headroom，所有调用仍经 Headroom；CC Switch 全局选择和桌面登录不受影响。AMD 固定绑定已移除。

入口仍是稳定 `scripts/xiaoba`。`doctor --json` 显示优先级候选、缺失项和本机代理启动状态；实际用到的 Provider 和模型见任务审计记录。远程调用失败后顺序尝试下一项；每项一次，全部失败即停止，下一任务重新首选。Claude 列表中没有 GPT plus / GPT pro 时不会跨读 Codex 或 Desktop 记录。

`intake` / `submit` 支持 `--context-file`，Bridge 支持 `task_context`。输入必须为最小、已筛选、带来源和时间的任务摘要；两个 Agent 共享冻结证据，各自检索历史记忆。哈希只证明完整性，不证明内容真实性。
