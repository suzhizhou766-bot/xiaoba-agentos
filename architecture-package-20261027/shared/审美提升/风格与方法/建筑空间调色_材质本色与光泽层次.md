# 建筑空间调色：材质本色与光泽层次

编号：STYLE-012。建档日期：2026-10-17。
状态：会所空间11张第二版已获用户明确采用；方法有本次实际制作和正反对照证据，跨项目复用尚未验证。正式经验发布另走AgentOS裁决。

## 这次学到什么

建筑空间的高级质感可以来自材料本色、原有高光反射、明暗分离和冷暖关系。不能把“统一、克制、高级”自动翻译成整体压灰、降低所有颜色的饱和度。

第一版侧重中性灰白、克制木色和低饱和自然绿。用户指出：“太灰了，感觉这样的调色失去了原本建筑和物体光泽的高级质感”。从原图重做第二版后，用户反馈：“第二版非常好，记录这次调色经验进小八第二大脑和审美手册”。两句原话限定了本次取舍，不代表用户以后所有题材都要求鲜艳、暖色或强反光。

## 本次实际执行

使用内置imagegen，以11张原始照片逐张编辑，没有把第一版继续加色当作第二版底图。共同提示词要求恢复材质的明暗和色彩区别，逐张补充照片中的实际对象与保留项；完整提示词留在项目 `第二版_材质光泽/来源与提示词_v2.json`。

| 对象 | 本次制作重点 | 输出检查 |
|---|---|---|
| 石材、浅色墙面 | 亮部通透，石纹与底色分开，保留光线渐变 | 不靠整体压成灰色显得稳重；亮面仍有纹理 |
| 木材 | 保留自然暖色和木纹明暗，避免全部去成灰米色 | 木色有厚度，逐图核对是否过橙 |
| 金属、龙头、不锈钢台面 | 原有高光、反射和暗面有区别 | 反射要有亮暗变化，不能均匀涂亮 |
| 白色设备、黑色器械 | 白色外壳保留光泽，黑色表面有受光边缘与暗部细节 | 白不糊成一片，黑不死也不浮灰 |
| 绿植与窗外 | 保留自然叶色和空间外景的色彩层次 | 不因统一风格把所有绿色去掉 |
| 室内混合光 | 保留原有暖灯与自然光差异，只纠正干扰性的偏色 | 不把全图统一染暖；新增光源和改变影形须另行授权与验收 |

## 下次怎样调用

先看真实材质和要表达的感受，再定颜色与明暗；使用本例作为有范围的参考。把“木材要有本色、金属要有反射、石材要有层次”落实到本张照片中的实际表面，按各图曝光分别匹配。整组统一的是材料表现与冷暖关系，不是每张套同一亮度或灰色滤镜。

生成后仍逐项核对构图、结构、文字、原有光影和材料细节。提示词写了“保留”不能代替检查。本例没有可验证的RAW调色曲线、HSL数值或LUT，也没有证明某一个单独参数导致结果改善；不能编造可复现参数。

## 采用范围与反例

- 已确认：用户认可本组第二版的调色效果，第一版压灰方向被否。
- 尚未确认：其他建筑、天气、商业任务是否适用；用户未逐张确认文字和建筑结构的保真。
- 反例：为了去灰而让木色橙红、植物荧光绿，或伪造高光、太阳光束，同样会破坏材料可信度。低饱和仍可用于合适题材，本例不作全局禁止。
- 工具边界：本批是10张1536×1024横图、1张1024×1536竖图的AI编辑效果版。文字、纹理和局部构图有重算；不等同于约32MP原片的传统精修母版。用户认可审美方向，不自动解除这些技术限制。

## 2026-10-22 知光集四图：最终采用原图4K调色

用户对AI调色预览先评价“非常好”，也喜欢其光影；但在原图4K调色、纯AI超分和AI光影加原图细节融合的最终对照后，明确“我认为还是原图4k调色舒服”，采用原图4K调色版。该版在原始3840×2160像素上参照AI匹配颜色与低频明暗，保留原有文字、结构和纹理，没有通过LR执行。

这补充了STYLE-012的交付取舍：材料本色与光泽方向成立，不代表模型重建或融合后的细节一定更舒服。AI预览认可不等于后续超分版本采用；每次规格/细节处理后仍看完整成片。用户未指明技术原因，不将不适归咎某个参数。结论限本组；类似建筑可先尝试原图保真调色、AI做参考，不作全局禁用超分规则。
