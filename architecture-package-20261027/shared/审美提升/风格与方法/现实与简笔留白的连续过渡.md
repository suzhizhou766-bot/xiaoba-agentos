# 现实与简笔留白的连续过渡

编号：STYLE-008。
名称性质：本模块的描述性工作名称，不宣称是艺术史正式流派。
建档日期：2026-10-08。
关系：连接原有“素描和涂鸦”与“灰白色色调”，补充跨表现方式的过渡方法；原有七方向保持独立。
状态：用户明确喜欢此类组合；视觉观察完成；制作规则为待实践验证的归纳；第二大脑发布状态另见候选登记。

## 核心表达

保持可以追踪的物体结构、空间和光照关系，让材质、颜色与细节逐渐减少，最后由线描和纸色留白承接。局部投影、倒影或色块可以继续存在，使简化后的物体仍有位置和重量。

结合留白区的小人物、重复形体或动作呼应，可形成第二层叙事。尺度变化属于创作选择，与“同一物体的物理连续简化”分开描述。

## 可复用的候选规则

| 编号 | 做法 | 适用条件与证据 | 验收观察与例外 |
|---|---|---|---|
| R01 | 选定一条可追踪的结构作为连接：树干、路缘、桌沿、吊线或伞骨 | 结构清晰的主体；参考03、05、11、12、13 | 从写实区沿轮廓能追到线描区；有意变形或比例叙事时另注明 |
| R02 | 先减少小纹理，再调整局部色块和明暗，最后保留必要轮廓 | 做同一物体的细节过渡；参考03、04、05 | 作为制作试验顺序，不能据成图断言作者实际流程；不要求所有位置严格按这个顺序 |
| R03 | 风格变化时保留关键阴影的方向、接触位置和合理的亮暗关系 | 主题依赖自然光或落地感；参考06、07、12 | 检查是否悬浮、投影是否突然转向；线描区可降低阴影强度，但仍应能解释其空间关系 |
| R04 | 用波纹、叶片、树皮或排线组织边界，使疏密变化跟随物体 | 水、植物和有纹理物体；参考02、03、04、09 | 过渡边界应能与主题发生关系；规则图形或明确版式分区可另选整齐边界 |
| R05 | 留白区保留少量关联色，必要时设置一个彩色焦点 | 希望延续情绪或强调故事；参考04、05、09、15 | 不要求全面去色；判断留下的颜色是否与主场景形成联系 |
| R06 | 根据叙事分配细节密度，留白区保留足以辨认的动作和结构 | 有人物或重复物体的画面；参考01、08、11、14、15 | 小人物动作缩小时仍可辨认；没有人物的任务也可使用此方法 |
| R07 | 对水面单独保持倒影与波纹的联系，并明确何处为真实反射、何处为叙事变化 | 水面题材；参考02、04、09 | 不把姿态变化、比例变化称为严格镜像；色彩连续与物理准确分别检查 |
| R08 | 字句作为可选的轻量叙事元素，位置和密度服从留白 | 本批样本常见短句 | 用户未单独确认喜欢英语手写短句；不把它变成强制模板 |

## 创作时的控制项

先明确主体、光源方向、需要保留的结构与叙事类型，再选过渡范围。分别控制纹理密度、颜色保留、阴影强度、线条密度和纸色背景，不把这些变量绑定为一个“淡出强度”。

纸色暖白只是本组常见条件，可与冷白、其他背景或其他过渡方向做对照。用户尚未确认所有作品都采用暖白、竖版、上下布局或小人物。

## 建议练习

同一张主体参考，先做一版只减少材质细节、一版同时保留接触阴影、一版加入少量关联色。保持主体轮廓与构图相近，用用户反馈判断哪些变量更接近目标。
