# 低饱和冷暖分离：图像编辑练习草稿
日期：2026-10-09。对应STYLE-011。
性质：助手原创组织的练习文本；不是作者原提示词、不是已验证配方，也不是实际生成作品。
条件：使用自己有权编辑的原图，先确认图像编辑模型、设置和是否支持负向提示。本轮未调用生成服务。

## A版｜只调整颜色和影调
对输入照片进行克制的颜色与明暗调整。保持原画幅、主体大小位置、道路和门窗的几何关系；保留图中文字、刻度与装饰图案。保留当前光源和所有投影的方向、位置、形状；不新增照明、云层、人物或物体。
让背光区域略偏冷、已有受光区域略偏暖，减弱无关颜色的竞争，保留主体材料原有身份。暗处仍能辨出边界与纹理，亮部保留细节。维持原有前后景清晰关系，不添加景深模糊。只改变颜色和影调；无法在保留场景的条件下实现时，减少变化并明确说明。
这段文字是任务约束，遵守情况需实际检查，不保证模型必然满足。

## B版｜同样构图，增加少量材质表达
以通过A版结构检查的结果为输入，保持全部结构及光照限制，只增加少量细颗粒和局部质感；正常阅读尺寸下颗粒不抢主体、边缘不出现明显光晕。
与A版比较。如果颗粒造成材料变样、纹理重画或字样不可读，则撤销该项。不能通过描述“胶片”“8K”等证明结果细节正确。

## 可选C版｜用户允许时另做光照重设计
独立说明新光源方向、范围以及所有应受影响的物体。不要沿用“原光影保持”的标签；不能让其结果替代A版验收。本轮没有获得对具体图片重设计光线或生成成品的采用意见，故仅记录选项。

## 对照与反馈
- 是否只改变了允许的项目：构图、几何、物体数量、文字/刻度、光源和投影逐项核对。
- 是否更符合目标：主体主次、空间深度、材质层次、冷暖关系。
- 对照条件：统一裁切和显示尺寸，保存模型、设置、输入文件及实际变化记录。
- 用户反馈分别关联A/B/C；无回应不代表采用。暂无实际结果和成功率。
