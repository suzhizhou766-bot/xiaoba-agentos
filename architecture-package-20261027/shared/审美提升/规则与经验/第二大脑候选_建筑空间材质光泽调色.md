# 建筑空间调色：按材质本色、反射与明暗层次组织，而非统一压灰

类型：method候选。日期：2026-10-17。问题标识：aesthetics.interior.material-luster。

## 实际案例及用户结论

用户提供11张会所空间照片。第一版以中性灰白、克制木色、低饱和绿统一，用户指出：“太灰了，感觉这样的调色失去了原本建筑和物体光泽的高级质感”。第二版从11张原图逐张使用内置imagegen重做，重点恢复材质本色、原有高光反射、明暗分离及冷暖光差。用户交齐后反馈：“第二版非常好，记录这次调色经验进小八第二大脑和审美手册”。

本案例已实际执行并获审美采用；跨项目复用、各变量独立贡献尚未验证。没有将旧规则候选改写成已完成版本。

## 方法归纳

1. 先确定题材与感受，再逐项识别石材、木材、金属、白色设备、黑色器械和植物各自需保留的色彩与反射特征；不把统一、高级直接解释成全局去饱和或压灰。
2. 返修从原图开始，逐图匹配曝光和白平衡；让石材的亮面和纹理分开、木材保留本色、金属保留反射变化、黑白设备保持表面层次。整组统一材料表现与冷暖关系，不强行统一亮度。
3. 保留原有暖灯与自然光区别，纠正干扰性偏色；要求保留原结构、文字、镜面内容和光影。实际输出逐项核对，不能凭提示词声称全部锁定。
4. 把正反版本与用户原话关联保存。色调方向采用与文字/纹理/结构/分辨率保真分别记录，不从一次采用推出全局风格或商业母版通过。

这里没有可验证的RAW曲线、HSL数值、LUT或单参数效果，不伪造可复现参数。全局增饱和、橙化木色、荧光绿或新增光束也不是本方法的目标。
