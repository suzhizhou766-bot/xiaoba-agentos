# 审美方向与学习方案

日期：2026-10-08
状态：讨论稿。七个方向由用户提出；分类、组合、练习和目录方案为助手建议，尚未经用户最终采用。

## 一、提升目标

2026-10-11用户明确最终目标：提炼出小八的taste。作品采集、知识与方法积累应逐渐转成有理由的选择和取舍，并在真实任务与用户反馈中检验。具体能力定义与验收提案见`结构与知识/小八的taste_形成目标与判断框架.md`；目标已确认，不代表框架或具体风格已经采用。

小八应逐渐能够说明：画面有什么；哪些关系产生了某种感受；不同方案如何取舍；这些判断怎样转成可执行的创作条件；用户的具体反馈怎样改变下一次选择。

分开积累两类能力：

1. 审美判断能力：观察、比较、结构分析、识别失败与提出改进。
2. 用户审美理解：用户在特定场景喜欢什么、排斥什么，以及反馈的时间和范围。

用户列出探索方向，不等于已经认可所有方向的全部作品，更不能推导出全局偏好。

## 二、七个方向的工作分类

下面用于安排练习，不作为艺术史上的正式分类。

| 用户方向 | 主要练习维度 | 可比较的变量 | 候选组合 |
|---|---|---|---|
| ASCII和像素 / ASCII and pixels | 离散元素与信息简化 | 字符或像素密度、轮廓可读性、灰阶、尺度；两种表达分别观察 | 灰白背景上的稀疏字符或低分辨率形体 |
| 素描和涂鸦 / sketch and scribble | 线条与手势 | 粗细、压力感、疏密、重复、留白；素描与涂鸦不合并成一套规则 | 铅笔灰线条与自由涂写的对照 |
| 数字印象派 / digital impressionism | 色块、笔触与光感 | 边缘清晰度、色块关系、光色变化、局部与整体识别 | 低饱和光色与可辨认主体的试验 |
| 变形物体 / morphing objects | 形态与变化过程 | 变形幅度、连接方式、材质、重心、静态姿态与动态连续性 | 同一物体在灰白空间中逐步变形 |
| 洛莫图像 / lomo imagery | 摄影画面气质 | 对比、偏色、暗角、颗粒、偶然构图；具体特征由样本确认 | 灰白主题与偏色、颗粒之间的对照 |
| 生成艺术 / generative art | 规则与变化 | 重复、随机程度、密度、秩序、可复现参数 | 线条或像素在明确规则下生成变体 |
| 灰白色色调 / shades of off-white | 色调与材质关系 | 暖冷、明度、纸感、表面粗糙度、阴影层次 | 作为部分练习的共同背景，再与彩色版本比较 |

## 三、第一阶段的试验建议

先选同一个中性主体，例如杯子、石头或抽象形体，用相近画幅和主体尺度，分别做七个方向的练习。固定主体有助于比较表达差异。

灰白色调可以作为一条共同试验线，但不提前设为全局风格。某些方向可再做一个彩色对照版本，观察灰白限制是否损失了原有特征。

先比较三个组合：

- 灰白 + 素描/涂鸦：线条、留白与手工痕迹。
- 灰白 + 变形物体：材质、体积与形态张力。
- ASCII/像素 + 生成艺术：离散元素、秩序与变化。

以上只是试验提案，没有已经生成或验收的作品。

## 四、一次学习的完整循环

看样本 → 记录可见事实 → 提出解释 → 制作对照 → 用户反馈 → 提炼候选 → 新任务复用 → 复盘。

每张样本卡记录：编号、来源、作者或出处、获取日期、领域、方向、图像或原文件位置、可见事实、待验证解释、值得借鉴之处、失败点与限制。

每次试验尽量只改变一项主要变量，例如线条密度、画面明度或变形幅度。用户反馈使用原意明确的摘要，并关联到实际方案；不从一次喜欢推导出永久规则。

规则卡建议字段：编号、规则表述、类型（方法/知识/个人偏好）、证据样本、适用场景、禁用或例外条件、反例、用户反馈、状态、最后复验时间、关联试验位置。

学习进展以结果衡量：能否指出具体差异、给出可执行改动、说明适用条件，并在后续任务中获得用户采用；不以收藏量或笔记数量代替。

## 五、拟议资料结构

后续有内容时逐步建立，不预先制造空资料或虚构经验：

- `方向与基础/`：术语、观察维度、用户明确表达的探索目标。
- `样本与拆解/`：来源、样本卡、参考图或原项目位置。
- `对照与练习/`：方案、变量、结果、用户反馈。
- `规则与经验/`：方法、偏好、失败经验；各条分别标明审核状态。
- `结构与知识/`：可复用的分析框架、风格组合、知识卡。
- `复用与复盘/`：哪些任务用了哪些资料，结果如何，需要怎样修订。

使用已有 AI视频管线视觉知识库时只记录其原文位置和必要摘要，不搬走或复制整套既有资料。

保持现有单父树结构；入口、资产卡、经验卡各自在对应分支登记一次，跨分支关联使用普通文字或来源路径。后续第二大脑目录改名时按实际活动配置更新，不写死未来路径。

拟议复用流程：先确定任务场景和目标 → 检索入口 → 回读原文 → 筛选已确认且适用的规则 → 生成方案 → 比较验收 → 记录复用反馈。候选可供讨论与试验，不能被当成已确认的用户偏好或权威规则。

正式发布与可检索验收应分别确认：候选审核状态、正式笔记位置、索引复验结果，以及实际检索命中并能回读原文。
