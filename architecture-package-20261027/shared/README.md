# 小八私人助理工作区

这里是小八的地盘：规则、技能、工具、第二大脑和可复用的媒体资产都放在这个目录下，统一管理。任何 Agent 通过小八干活产出的有价值的东西，也都存到这里，不留在某个 Agent 自己的私有目录里。

Agent 的行为规则在 `AGENTS.md`，以它为准；本文件只说明这里有什么。

## 权威入口

1. `AGENTS.md`：所有 Agent 的通用入口和规则。
2. `第二大脑/00_小八AgentOS.md`：第二大脑的根笔记，唯一事实源从这里进入。
3. `第二大脑/10_治理与裁决/运行宪法.md`：最高层的运行规则。
4. `第二大脑/60_当前上下文/系统当前态.md`：当前运行的版本和状态。

目录名 `第二大脑` 和根笔记文件名 `00_小八AgentOS.md` 不含版本号（2026-10-10 随 v1.5.1 一次性去掉），此后不随版本变化；再改名会断开 Obsidian 绑定和索引。

找东西先检索，再读原文：

```sh
XIAOBA="$HOME/.agents/skills/xiaoba-agentos/scripts/xiaoba"
"$XIAOBA" memory-retrieve "要找的内容"
"$XIAOBA" skill-match "要做的事"
```

## 常用入口

- 小八监看中心：双击 `工具/小八监看/启动监看中心.command` 开启，`关闭监看中心.command` 关闭；不开机自启。
- 上班、下班、任务状态、裁决：见 `~/.agents/skills/xiaoba-agentos/SKILL.md`。
- 模块契约检查：

  ```bash
  XIAOBA_ASSISTANT_ROOT="$HOME/Documents/私人助理" \
  KNOWLP_ROOT="$HOME/Documents/Codex/KnowLP" \
  python3 工具/治理/xiaoba_contract_check.py --json
  ```

- 提示词反推、深度图、超分三个本地服务：监看中心开着时，在导演台里点开关即可。

## 卫生规则

- 不在本目录保存旧恢复包、认证会话副本、迁移验收成片或已退役工具链。
- 缓存、烟测产物和项目临时素材完成验证后删除。
- 正式项目交付进入 `AI视频管线/05_输出/交付/<项目名>/<版本>/`，长期保留由用户验收决定。
- 第二大脑不存项目素材，不把聊天、索引或运行状态当成事实源。
- 没有用户直接、明确的要求，不新建备份。
