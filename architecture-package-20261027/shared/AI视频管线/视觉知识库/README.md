# AI建筑视频导演视觉知识库

最后更新：2026-08-09
定位：从优秀视频反向提取镜头、光影、动态、材质、提示词，形成可复用的导演视觉资产。

## 学习节奏（宁深勿多）

1. 每次只深挖 1-2 条最优秀的视频。
2. 用 `01_视频拆解/视频拆解模板.md` 做七步拆解。
3. 拆解结果分类入库；每 10 条做一次批量归纳。
4. 目标输出：分镜脚本、AI视频提示词、镜头设计规范、视觉风格模板。

## 目录规划

- `01_视频拆解/`：单条深挖原始记录
- `02_镜头库/`：空间进入、环绕展示、微距材质、穿越
- `03_光影库/`：日光、黄昏、夜景、科技扫描光
- `04_动态库/`：生长、解构、重组、粒子生成
- `05_提示词库/`：Kling、即梦、Veo、Seedance 已验证提示词 + 提示词系统文档索引（CINEDANCE V4 / Lira / ACTING SYSTEM，见 `05_提示词库/README.md`）

## 单条拆解七步

视频结构 → 镜头语言 → 摄影逻辑 → 光影规律 → 材质表达 → AI生成关键词 → Skill知识模块

## 入库规则

- 每条视频拆解后至少提取 1 个可复用镜头、1 条光影规律、1 条材质表达、1 条提示词。
- 参考视频必须记录来源，避免无出处资产。
- 批量归纳前先完成单条拆解，禁止直接批量丢视频。
