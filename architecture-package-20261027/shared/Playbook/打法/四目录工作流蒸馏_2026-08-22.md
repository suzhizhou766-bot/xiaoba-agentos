# 四目录工作流蒸馏

## 已固化的方法

1. 原始资产、机器索引、服务入口和交付 QC 必须分层：原始音效库不直接进入上下文，Codex 通过索引或 SFX 服务检索。
2. SFX 链路固定为：音效库 → 指纹扫描 → v3 指纹索引 → profile/duration 匹配 → 采用/评分日志 → 精选升级。
3. 视觉知识先做拆解，再分别沉淀到镜头、光影、动态、提示词库；不要把案例原文当成通用规则。
4. 提示词系统分工：CINEDANCE 管视频镜头结构，Lira 管图像模型路由与编辑，ACTING 管角色表演和状态连续性。
5. 交付链路必须经过渲染、48 kHz 音频 QC、资产清单；项目脚本产生的 44.1 kHz 音轨先转码再进入正式交付。
6. 同一项目的草稿、变体和最终版只保留一个权威入口；完成蒸馏并经用户确认后，项目性文件可以删除。

## 本次项目中保留的通用经验

- 声音包装以 BGM 为主体，SFX 只服务动作点、转场点、信息点和空间质感。
- 视觉生成优先锁定空间走位、光学、光影和物理连续性，再补风格词和模型参数。
- 项目结束后的长期资产是规则、索引和 QC 经验，不是每个版本的媒体文件。
