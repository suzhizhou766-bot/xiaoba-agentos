# 打法

这里记录可跨项目复用的执行工作流。项目文案、素材和一次性试听页不直接放入此处。

## 标准闭环

```text
需求/素材
  → 决策卡与源文件确认
  → 视觉/声音/提示词规则路由
  → 生成或合成
  → 技术 QC 与资产清单
  → 反馈/采用记录
  → 蒸馏为可复用规则
  → 用户确认后清理项目产物
```
