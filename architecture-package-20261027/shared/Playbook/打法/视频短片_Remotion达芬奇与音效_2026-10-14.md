# 视频短片：Remotion 出画面、达芬奇剪混、音效库配声

## 流程
1. **先读**：审美手册的 taste 卡、相关样本卡；声音部分先跑 `skill-match` 并读 `skills/bgm/SKILL.md` 全文和它指向的 references（作曲框架、音频验收），事前写「小八 BGM 决策」卡；事实类片子先从第二大脑、Playbook 取原文。
2. **一张时间表管全片**：把每个画面事件的帧号写在一个数据文件里（如 `timeline.ts`、`script.ts`），画面和声音都按它对齐。达芬奇搭建脚本里的音效落点直接用这些帧号。
3. **声音先于画面定节奏**（参考片的做法，小八这次没做到）：先选配乐、测出速度和段落，把换场、换字放到重拍上，再写画面动画。
4. **Remotion 出画面母版**：`npx remotion render src/index.ts <ID> out/x.mov --codec=prores --prores-profile=hq --muted --color-space=bt709`。不带声音，专给达芬奇用。
5. **先出静帧检查**：`npx remotion still ... --frame=N`，挑每段关键帧看构图、字号、遮挡，再出全片。
6. **达芬奇搭工程**：用脚本新建独立工程，导入画面和音效，按时间表铺多条音轨，设音量和淡入淡出，打章节标记，然后出 H.264。
7. **先渲染到工作目录**，测完规格、响度、峰值，再移进 `05_输出/交付/<项目>/<版本>/`，补技术验收、元数据、素材清单、缩略图。

## 声音
- 素材从 `音效素材库` 取。匹配器 `AI视频管线/scripts/sfx_match.py <模板> <时长>` 只覆盖 whoosh、impact、ambient、transition 等几类；乐器和配乐要直接查 `音效素材库索引.csv`。
- 听不到声音时，用测量挑选：ffmpeg 的 `ebur128` 测响度和真峰值；numpy 算每秒 RMS、频谱重心、音头密度、速度。挑完要说明“没听过”，让用户把关。
- 用户要的：每次换场有 whoosh 或上升音；音乐要有段落起伏（参考片段落之间低频差约 10 dB），至少安排一次“抽走—落地”；画面换字踩在重拍上。
- 响度：信息流短片做到约 -15 到 -16 LUFS、真峰值 -1 以内；参考片是 -14.7 LUFS、LRA 3.3。混音后按“每半秒峰值”找削波点，再单独压那一声。
- 库里没有现成的“有段落的长配乐”时的做法（v004 用过）：挑一首自带起伏的长曲（如 `软音乐/FS_suavity_069`，53 秒，约 90.7 BPM，0–15 秒安静、15 秒低音进、16–35 满、35–40 回落、40–50 再满），测出它的低音重拍位置，再按片子的章节把它的安静段、回落段、满段剪到需要的位置；剪点选在低音重拍上，接口压在 whoosh 下。需要“抽走”的段落（如做减法、写“8”之前）直接撤掉配乐，只留动作声和上升音，落地处用重击加满段。whoosh、上升音按“素材最响的那一刻对准换场帧”倒推起点。同一条音轨上的片段不能重叠，会被顺延或放不上，重叠的放到新音轨。
- 听不到声音时给用户看的证据：用 ffmpeg `showwavespic` 画整片波形，标上段落名（v004 交付目录里的 `响度曲线.png`）。
- 小八这次用过、能用的素材：钢琴背景（59.6 秒，平稳，-20.6 LUFS，没有段落，单独当整片配乐会显得平）、写字画画（笔声）、盖章音效（峰值 0 dBFS，要降到 -5 dB 左右）、颂钵（长尾，适合收尾）、Clean soft whoosh #1（精选，暖，适合塌缩/转场）、Hollogram Pad-004（偏亮的底）、单音1（很短的落点音）。

## Remotion
- 工程：`工具/Remotion`（4.0.535）。在 `src/Root.tsx` 登记 Composition；类型检查 `npx tsc --noEmit`。Studio 由用户手动开，命令行渲染不需要开 Studio。
- 字体：放进 `public/fonts/`，用 `FontFace` + `delayRender` 加载；15 MB 的中文字体首帧会超时，`delayRender` 要给 `timeoutInMilliseconds: 120000`。系统字体（Menlo、PingFang SC）可直接按名字用。
- 线条“画出来”：`pathLength={1}` + `strokeDasharray="1 1"` + `strokeDashoffset={1-p}`；拉远时加 `vectorEffect="non-scaling-stroke"` 保住线宽。
- 手绘抖动用 `feTurbulence` + `feDisplacementMap`：频率 0.006、强度 2.2 左右才稳；频率 0.018、强度 3.5 会把直线打成虚线。
- 颗粒用全屏 `feTurbulence`，每 2 帧换 seed，`mix-blend-mode: multiply`，不透明度 0.07。

## 达芬奇（脚本接口，Resolve Studio 21.1.1）
- 每次调用都要先设 `RESOLVE_SCRIPT_API`、`RESOLVE_SCRIPT_LIB`、`PYTHONPATH` 三个环境变量（见第二大脑 `20_能力与技能/达芬奇`），用 `/usr/bin/python3`。
- 新建工程后先 `SetSetting` 分辨率和帧率，再导入、建时间线。
- 放片段：`MediaPool.AppendToTimeline([{mediaPoolItem, startFrame, endFrame, mediaType: 2, trackIndex, recordFrame}])`，`recordFrame` 要加 `timeline.GetStartFrame()`。`endFrame` 不含末帧，写 `start + length`。
- 音量：`TimelineItem.SetProperties({"AudioVolumeEnabled": True, "AudioVolume": dB})`；淡入淡出：`SetFades({"FadeIn": 帧, "FadeOut": 帧})`。
- 出片：`SetCurrentRenderFormatAndCodec("mp4", "H264")` → `SetRenderSettings({...TargetDir, CustomName, AudioCodec: "aac", AudioSampleRate: 48000})` → `AddRenderJob()` → `StartRendering([job])`，用 `IsRenderingInProgress()` 等。75 秒 1080p 约 10 秒出完。
- 搭建脚本写成可重跑：工程存在就打开，删掉同名时间线再重建；每放一段读回 `GetStart()` 核对位置。

## 交付
- 视频管线规定正式交付走 `AI视频管线/scripts/pipeline.sh`。2026-10-15 起它有外部成片模式：`pipeline.sh <项目名> --video <达芬奇成片或 Remotion 母版> --premix <达芬奇导出的总轨> --attach <分轨/报告/时间轴>... --version vNNN`，跳过渲染和 BGM/SFX 预混，照跑 audio_qc、技术验收、内容预检、元数据和资产清单。达芬奇做完的片子一律这样交，不再手工拼交付目录。
- 版本目录不能覆盖，所以迭代期一律渲染到工作目录，定稿再进交付目录。
- 声音交付按 bgm 技能交五个文件：BGM 单轨、SFX 单轨、预混总轨（48k WAV）、音乐结构与混音验收报告、音效时间轴 CSV。分轨要用“只含部分声音的临时时间线”出（脚本里关掉音轨对出片无效），导出后比 MD5，并做“分轨相加减总混音”的抵消检查。达芬奇脚本接口的 WAV 格式列不出编码器，可导出带 LPCM 音频的 MOV，再用 ffmpeg 原样抽成 WAV。`skills/bgm/scripts/audio_qc.py` 读不了 24 bit 扩展格式头的 WAV（2026-10-14 未修）。
