# 小八监看中心

本机页面 `http://127.0.0.1:8799/`，五个模块：**运行总览**、**裁决中心**、**导演台**、**3D 导演台**、**Key 池**。工具目录 `工具/小八监看/`，完整说明在该目录的 `README.md`（改代码前必读对应章节）。

## 开与关

- 开：用户双击 `工具/小八监看/启动监看中心.command`；关：`关闭监看中心.command`。**不开机自启，不装 LaunchAgent。** Agent 发现没开时提示用户，不要自己拉起常驻进程。
- 解释器：统一用 `配置/python/cpython-3.14.7-macos-aarch64-none/bin/python3.14`（启动脚本已写死）；裁决后端的解释器在 `monitor.json` 的 `review.python`。
- 健康：`/healthz`（存活）、`/api/health`（各模块）。

## 端口（默认值在 `monitor_core/config.py`，覆盖写 `monitor.json`）

| 端口 | 用途 |
|---|---|
| 8799 | 监看中心本体 |
| 8780 | Key 池代理（随监看中心启停） |
| 8893 | 导演台本地工具控制器（监看中心看护） |
| 8890–8892 | 控制器管的反推、深度、超分（开关决定，不随监看中心自动起） |
| 临时 | 裁决后端，端口记在 `run/review-backend.json` |

## 各模块要点

- **运行总览**：只读 AgentOS 的数据库、日志和状态文件，不写。
- **裁决中心**：逻辑是 `小八AgentOS/integrations/review-center/server.py`，监看中心只负责拉起和看护。**任何 Agent 和脚本都不得替用户批准候选。** 没开时待审队列不同步第二大脑，开启后自动补上。
- **导演台**：`director.html`。本地工具开关走 8893 控制器。
- **3D 导演台**：源码 `工具/小八监看/小八3D导演台/`，改源码后在该目录 `npm run build`，刷新页面即可。**`工具/小八监看/小八3D导演台/工程库/` 是用户数据，不得清理、移动或重置。**
- **Key 池**：密钥库 `keypool.json`（600，Agent 不读不写不复制）；`run/keypool.json` 只是运行状态（pid/port），两个同名文件别搞混。Agent 用 Key 池只走 `http://127.0.0.1:8780` 的合并 Key 接口，不碰节点 Key。

## 改代码

1. 先读 `README.md` 对应章节和 `Playbook/偏好` 里监看相关条目（界面统一 Apple Liquid Glass 风格；视觉改版先出几版设计稿，用户定了再落地；不直接改线上页面）。
2. 页面类视觉判断先读审美手册 `审美提升/审美手册.md`。
3. 新模块按 README「加一个新模块」四步，并补测试。
4. 自检与测试（3.14.7）：`<py> xiaoba_monitor.py --selftest`；`<py> -m unittest discover -s tests`（临时端口、假后端，不碰真实数据）。
