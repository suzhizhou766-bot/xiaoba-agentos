# 语义 → 画面对照表

**来源**：44 支 Opus 5.5 代码视频样片（lemo-opuscar 全系列）加 4 支未公开的 Opus 成片，逐支记录了「抽象概念被转成了什么具体东西」，再按概念的类型归类。括号里是用了这种画法的片子。

---

## 一、找画面的 4 种方法

按顺序试，用第一个能用的方法。

1. **找它在现实里看得见的样子**：这个概念发生时，现实里有什么东西会变？要找数得出、会变化的东西。
   - 时间 → 钟面在走、引线在烧；规模 → 同一个图标重复几千次。
2. **字面化 / 双关**：把这个词的字面意思直接画出来。
   - 「改进设计」→ 图纸上的修订云真的变成一朵云（blueprint）；
   - 「挥剑断水」→ 那一剑就是在空中写出的「水」字（ink-wash）；
   - 「我还在」→ 这句话的字母本身拼成地球（ascii-crt）。
3. **借一个观众熟悉的系统**：用另一个大家都懂的系统的结构，套到要讲的东西上。
   - AI 发展 = 游戏关卡（game-show）
   - 城市交通 = 一首乐曲（tilt-shift）
   - 猫的日常 = 刑事案卷（halftone-dossier）
   - 设计规则 = 五线谱（swiss-motion）
   - 工作流 = 地铁线路 / 拼装说明书
   - 这一层通常就是整支片子的「媒介」，风格库已经替你选好了。
4. **用媒介本身的物理**：让这个风格的材料特性直接表达意思。
   - 皮影戏里「射下太阳」= 灭掉幕后的一盏灯（shadow-puppet）；
   - 版画「真相显现」= 反写的版印成正向的画（woodcut）；
   - 纸上没印墨的留白，就是画面里最亮的瀑布（silkscreen-poster）。

## 二、对照表：常见概念类型 → 样片里的具体画法

| 概念类型 | 具体画法 | 样片例子 |
|---|---|---|
| **时间 / 时间压力 / 流逝** | 钟面、楼层编号、倒计时；一根打结的引线每拍烧过一个结；阳光从一扇窗移到另一扇；整张画面的配色从白天换到黄昏；屏幕时钟突然跳 3 小时 | art-deco、microgame、stained-glass、silkscreen-poster、backrooms、cel-anime-80s |
| **数量多 / 规模大 / 信息过载** | 同一个图标重复几千次（Isotype）；元素一层层越堆越多；大数字一个个砸上屏；放大一个符号，里面密密麻麻全是记录；一个方块越吹越大 | iso-infographic、dark-keynote、pictogram-motion、ascii-crt、game-show |
| **很多里的一个 / 只对一部分成立** | 满屏灰色里唯一一个彩色，加追踪圈；点阵小人里只有一部分亮起；聚光灯只照一个；全片唯一的强调色只给它 | iso-infographic、living-screencast、woodcut |
| **筛选 / 提炼** | 点阵逐级减少（1,399 → 168 → 7）；不合格的被打叉、变灰、掉出画面 | 未公开实验片 |
| **整理 / 秩序 / 多变一** | 散乱元素按种类飞进网格；整面图标墙塌缩成一个；满屏卡片飞回宫格 | dark-keynote、pictogram-motion |
| **路程 / 进度 / 步骤** | 地图上一条虚线，站点就是步骤；一座山在画面里从一粒米变到撑满全屏；剖面图里一个红点往上爬；镜头沿着路线走一遍 | iso-infographic、ukiyoe、art-deco、watercolor、silkscreen-poster |
| **情绪 / 状态变化** | 颜色回来（被听见）或褪色（悲伤）；网点密度变高（可爱到爆炸）；一盏灯的亮度当情绪表；人物上色后才会动 | impasto、pixel-rpg、halftone-dossier、hd-2d、urban-sketch |
| **成功 / 判决 / 完成** | 盖章（WORKS、结案、不讲）；打勾；全片唯一一次出现的异色只给这一下 | blueprint、halftone-dossier、midcentury-toon |
| **障碍 / 失败** | 一道巨浪、一团湿墨压过来；吊桥升起；HP 归零、名字变灰；塔塌掉 | ink-wash、ukiyoe、cel-anime-80s、pixel-rpg、brick-toy |
| **失败变成资源** | 塌掉的塔变成重搭的零件；丢掉一条命的那个喷嚏，后来绽开成降落伞 | brick-toy、microgame |
| **修正 / 重来 / 改变心意** | 黑板擦倒着擦掉轨迹（倒带）；海浪把版画洗回白纸再重印；碎玻璃沿铅条滑动、重新焊好 | whiteboard、ukiyoe、stained-glass |
| **系统在做什么（软件能力、AI 动作）** | 一个小角色在界面上走：沿文件树跑过 = 读文件，站在消息上 = 发消息；产品被扫描、锁定、拆开；数值从 30 滚到 80 | living-screencast、hologram-hud |
| **对比：两种做法 / 前后** | 同一样东西放两条轨道上并排比（每帧 1 次 vs 10 次）；两条时间轴越走越错开；被外光照亮 → 自己发光 | whiteboard、glass-product |
| **传承 / 循环** | 下一个人重复同一个动作；手接过笔再画一次开头的东西；远处另一座岛「听见」第一个音 | one-line、silent-film、lowpoly-island |
| **一生 / 全貌 / 原来如此** | 一根不断的线；整条卷轴几段并排；最后拉远，前面都是一张大图的局部 | one-line、ukiyoe、crayon-book、ink-wash、whiteboard |
| **选择太多 / 犹豫** | 列表刷屏、变糊；光标在几张卡之间来回晃，头上冒问号；路口插满路牌 | 未公开实验片 |

## 三、四条规则

1. **一个概念只用一个道具，而且这个道具要变**：有前后两种状态，变化本身就是意思。
   - 例：「默认值高」= 对着空输入框点发送（前）→ 分数表冲到 90（后）。
   - 只摆一个东西不变化，是在贴图，不是在演。
2. **用观众见过的东西**：输入框、钟、地图、盖章、路牌、灯、积木，比几何符号好懂得多。
   - 输掉的版本里，「默认值高」画成了一个换颜色的 3D 圆环，没人看得懂。
3. **遮字检验**：把屏幕上的字全部遮住，只看画面，能说出这一段在讲什么吗？说不出来就换画面。
4. **画面演意思，字幕只做补充**：直接把比喻写成一行字（比如「X 就是说明书」），是样片分析里最弱的一类做法。

## 四、写进 PLAN.md 的格式

每一句旁白或每一个要点，都填一行：

| 时间 | 这句话的意思 | 概念类型（查上表） | 道具 | 前 → 后 | 遮字能看懂吗 |
|---|---|---|---|---|---|
| 0–2.6s | AI 视频已经不需要 skill | 判决 | 一墙 skill 卡片 | 满墙 → 被一道线划掉、计数归零 | 能：东西被清空了 |

每一行都填完再写代码。填不出来的那句，说明还没想清楚怎么演。
