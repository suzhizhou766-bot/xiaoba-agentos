# 手艺细节：运动、声音、版式的数值

导演手册（项目里的 `AGENTS.md`）定方向，这里给写代码时要用的具体数值。风格规范 `frame.md` 有自己的数值时，以它为准。

## 版式

- **安全区**：用 `lib.mjs` 的 `SAFE`。竖版：关键内容放在 x 90–920、y 220–1480 之内（手机全屏左右各裁约 45px，右边是点赞栏，底部是标题）。横版：没有平台遮挡，四边各留 5%（x 96–1824、y 54–1026）。
- **字号**：大标题 ≥ 96px，主句 ≥ 60px，说明 ≥ 44px，任何字 ≥ 26px（横版同样适用：画面高只有 1080，字号下限不变）。
- **焦点**：一屏一个视觉焦点。默认左对齐到 x = 90，居中留给结尾的大字。
- **字的底**：压在花背景上的字放在实心面板上，或用 `scrim()` 压暗背景。
- **数字**：每个数字带上单位、比较对象或来源。
- **颜色**：每段最多加一个辅助色，同一屏 ≤ 4 种颜色。
- **停留时的慢推** ≤ 2%（贴边内容不被推出手机屏）；段落之间的推、拉、穿越按需要做到满屏。

## 运动

- **缓动**：用 `E` 里的缓动函数；匀速只给滚动和背景漂移。
- **进场** 0.25–0.35 秒（outQuint / outExpo / outBack，outBack 参数 ≤ 1.6）；**出场**更快，0.15–0.25 秒（inC）。
- **卡点**：砸入类（slamText、闪白）第一帧落拍；落地类（飞入、弹入）最后一帧落拍。
- **零件**：大字关键句 `slamText`，说明 `riseText`，关键词 `highlight`，数字 `countUp` + `lockPop`。
- **错相**（同一事件里各层错开，30fps）：主体 0 帧 → 相机 +2–4 帧 → 标签说明 +3–5 帧 → 阴影背景 +5–8 帧；一组元素依次出现，每个间隔 2–4 帧。每层用自己的 `prog(t, t0 + 延迟, …)`。
- **完整动作**：预备（反向 3–6%，0.08–0.15 秒）→ 冲击（0.15–0.3 秒，落拍）→ 过冲（5–10%）→ 回稳（0.15–0.3 秒）→ 余震（周围元素晚 3–6 帧轻弹，≤ 2%）。压扁拉伸来自速度，撞击帧压得最扁（≤ 15%）。
- **动量连续**：上一个动作的末速度是下一个动作的初速度；落地后顺着来的方向滑一小段再停。甩镜往哪走，下一屏主体就从那边带着速度进场。
- **弧线**：移动走弧线，不走直线；抛、甩、落都带一点弧度。
- **景深**：前景 / 中景 / 背景三层，镜头移动时位移比约 1.3 : 1.0 : 0.4。讲知识的片子前景可省，中景和背景分开动。
- **接触阴影**：落在台面上的元素下方有椭圆软阴影，离地越高越小越淡；全片光源方向统一。
- **快门模糊**：一帧移动超过约 80px 的东西用 `withShutter(ctx, t, draw)`。
- **同一种动画**连续最多用 2 次，第 3 次换一种。

## 转场

- 首选这个风格媒介本身的动作（墨晕开、纸翻页、擦除、屏幕切主题、图形变形成下一个画面），一支片只用一套。
- 兜底：`whip()` 甩镜（0.7 秒，切点在正中、落小节第一拍，方向轮换，whoosh 提前 0.35 秒）；`zoomThrough()` 放大穿越（0.5 秒，inC，结束落拍）。
- 硬切留给重音、计数、对比，每次都配一个声音；闪白只给主重音。

## 声音

- 声音事件比画面动作少：只给重音、落地、转折、揭晓配声音。
- 全片音效用同一组材质（纸、木、玻璃里挑一两种），过同一个混响。
- 有口播时人声最清楚：人声段配乐比人声低约 12 dB。

| 时刻 | 声音 |
|---|---|
| 重音（开场、转折、揭晓、结论） | `impact()` 或 `snare_hit` + `brass` |
| 主体落地、撞击 | 一个和材质匹配的短促声 |
| 转场 | 一个 `whoosh` |
| 数字锁定 | 一个 `ding` |

- 依次出现的元素，音高按 `PENTA` 往上走。字多的段落用 `halftime_bar`，高潮用 `groove_bar(section='B')`。
- 声画错位：预备音早 1–3 帧，撞击音落在接触帧，余震音晚 2–6 帧。
- 停顿时配乐和音效降到 −30 dB 以下或静音；停顿后的第一个声音最重。
- 响度 −14 LUFS，峰值 ≤ −1 dB（`render()` 自动处理）。

## 质感

- 画面干净，颗粒和噪点只在风格规范要求时出现（例如宣纸纹理、复古印刷）。
