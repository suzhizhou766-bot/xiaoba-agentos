# 素材

把项目从“文件做出来”推进到“版本可信、资产可追溯、交付可复用”。不删除文件、不覆盖原文、不把试听或预览缓存当正式母版。

## 扫描顺序

1. 扫描项目目录并记录相对路径、大小、修改时间和扩展名。
2. 按资产类型分组：原始文案、断句/格式版、优化版、图片、视频、BGM、SFX、总轨、脚本、表格、预览和临时文件。
3. 根据文件名和内容识别版本；不确定时标记 `待确认`，不要擅自重命名正式文件。
4. 检查原文是否仍存在；优化/润色版必须与原文并存并有明确标签。
5. 对 WAV/视频进行可解码、时长和关键技术参数检查。
6. 生成交付清单、版本说明、问题清单和验收报告。

## 文案保护

- `原文不改` 是硬门槛。
- 断句、停顿、标点和排版属于格式变体；润色、改写和增强表达属于内容变体，必须另存。
- 报告中分别列出 `原始版`、`确认版`、`优化版`，不以文件时间猜测内容权威性。

## 音频/视频验收

至少检查：存在、非空、可解码、容器、时长、采样率、声道、位深、是否完整、是否误拿预览缓存/临时 MP4、是否从 `0:00` 对齐。技术合格不代表结构和听感合格；引用 BGM Skill 的结构验收结果。

## 资产归档

默认建议的交付包：

```text
项目交付包/
├── 01_原始文案/
├── 02_确认版文案/
├── 03_执行分镜/
├── 04_BGM/
├── 05_SFX/
├── 06_混音总轨/
├── 07_视频成片/
├── 08_验收报告/
└── 09_版本说明/
```

不要为了整齐移动或删除用户文件；先生成清单，只有用户明确要求整理时才复制/归档。

## 音效库索引

使用运行时能力索引中登记并通过验证的 SFX catalog 工具同步资产目录。未登记或校验失败时只生成待执行清单，不猜测脚本路径。索引记录文件名、相对路径、来源、分类、用途、情绪/质感、强度、时长、格式、是否精选、使用项目、推荐级别、评分、使用次数、否定次数、最近使用、生成提示词、授权备注和 SHA256。

项目专用素材不自动升级为 `精选音效/`。使用至少 3 次或评分至少 4/5 只进入 `音效精选候选.csv`；必须经用户确认后才移动。同步器不删除、移动或重命名音频，且保留现有人工语义与授权字段。

## 输出

```text
项目名_资产清单.csv
项目名_版本说明.md
项目名_最终验收报告.md
项目名_交付目录建议.md
```
