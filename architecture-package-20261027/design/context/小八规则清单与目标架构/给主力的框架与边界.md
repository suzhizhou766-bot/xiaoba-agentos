## 四处矛盾的处理意见
1. 失败一侧的再探测：不是真矛盾。“不得二次探测”指探测失败后不得自动再探测、不得让同伴诊断；恢复任务所需的健康记录来自用户重新“上班”时的真实探针。处理：把规则文字改清楚，加上“自动”二字。
2. 额度耗尽后重不重试：不是真矛盾，是两样东西。账户额度和超时可以有限重试；单轮输出到上限不得原样重发，因为重发还会撞上限。处理：文档里把两者分开写。
3. 完成了但缺候选的任务要不要补登记：代码里有缺口。`_complete_with_memory_candidate_tx` 的补登记分支只看“已完成且没有候选”，没有检查这个任务是否被约束条件扣住、尚未放行。正常流程不会走到这里（调度器遇到约束是扣住而不是调用它），小克没有追完全部调用方，所以不能说它一定触发不了。处理：补登记前检查扣留状态，被扣住的不补；加一项测试。
4. 自动恢复动作的配置能不能不写：代码是对的（不写和写空列表都接受），是发布说明里“仅接受空列表”说得不准。处理：改文档。
