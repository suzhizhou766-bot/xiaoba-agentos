文档核实时发现的事实：
- Codex 不支持 `permissionDecision:"ask"`：钩子会被记为失败，工具照常执行。所以“需确认”档在 Codex 上等于放行，只有“禁止”档有效。
- AGY 的 `"allow"` 会自动批准、越过 AGY 自己的权限询问，所以守卫放行时不输出任何内容。AGY 怎么处理空输出交 V4 实测。
- 这次也把 AGY 草稿里错误的 hooks.json 格式改正了。

**fail-closed 的代价**：守卫坏了以后，Claude Code、Qoder 在所有项目里都无法执行命令、无法读写文件，Agent 也修不了。只能用户在终端里修复，或者从对应的 settings.json 里去掉 hooks 键。
