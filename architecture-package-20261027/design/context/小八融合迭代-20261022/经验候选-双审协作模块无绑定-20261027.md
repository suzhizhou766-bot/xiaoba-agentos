# 双审协作模块不得绑定具体后台

类型：rule。依据：用户2026-10-27明确要求将固定两个后台改为可自由更换，不给双审协作模块添加绑定值；此要求覆盖旧方案“不更换某两家”的范围。

模块职责是按本次任务计划组织独立审查与证据核验。具体后台、模型、客户端路径、驱动、固定主备身份或默认组合不在通用模块中内置；从外部已审核插件池与用户授权任务策略提供参与者和执行约束。插件负责客户端差异和模型来源解析。缺少计划或未知插件明确报错，不默认使用已有后台。

自由更换保留真实来源、计划版本、替换原因、旧结果与实际新执行；同一来源不能通过别名凑独立票，不能把旧PASS改贴给新后台或抹掉有效FAIL。工作阶段贡献者与审核阶段参与者分别选择，证据关系仍须核验。

本次完成的是架构/预览修订、契约与实现任务卡；正式运行代码、配置、插件登记和发布尚未实施，不宣称当前生产已可任意更换。
