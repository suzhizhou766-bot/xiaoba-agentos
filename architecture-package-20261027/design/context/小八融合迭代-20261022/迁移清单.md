- 3.9 只留给 v1.6.5 的兼容测试；守卫遇到 `/usr/bin/python3` 时要先问你。（已写进 policy.json）

### 第 2.5 步：你亲自搬凭据（我只给步骤，不碰文件）

1. 先停服务：`关闭监看中心.command`。
2. 把 `工具/小八监看/keypool.json` 搬到新位置，然后在 `工具/小八监看/monitor.json` 里写 `{"keypool":{"file":"<新绝对路径>"}}`。**注意别碰同名的 `run/keypool.json`**，那个是运行状态文件。
3. （反向代理已不再使用，整个移到了 `_待删/`，这一步取消。）
4. 运行 `xb-secret import elevenlabs 配置/elevenlabs.env BGM生成`，把 Key 收进密钥箱，再把原文件移到 `_待删/`。
5. 重启后验证：在 Key 池页面点“查询余额”，网关用旧 Key 试一次，再打开 `http://127.0.0.1:8799/healthz`。
6. 顺手轮换 `~/.qoder/settings.json` 里的明文 Key。（M1）
