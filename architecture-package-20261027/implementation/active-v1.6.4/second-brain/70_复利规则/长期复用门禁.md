# 长期复用门禁

候选经验必须同时满足：来源可追溯、事实已核验、交付初审通过、下班终审通过、适用边界明确、与当前规则不冲突、不会携带凭据或项目隐私，并在发布后通过索引复验。

检索命中只表示找到候选，不表示它仍然正确。复用结果由新任务的用户终审确认；失败进入复验，连续失败达到配置阈值后从活动索引退役，但保留可恢复归档。

技能更新必须重建哈希索引并通过结构、功能、安全和回归测试。价值文件变化必须重建目录哈希；哈希失配时只报告过期，不继续调用。
