# 用户公共规则

## 备份授权

- 没有用户直接、明确的备份要求，不得自行新建备份文件、备份目录或备份快照。
- 可以提醒用户是否需要备份；提醒、一般操作授权或发布授权都不等于备份授权。
- 本用户规则优先于工作流、技能和发布脚本的默认备份建议；未经明确授权，不得执行内置备份步骤。
- 本规则不授权自动删除已有备份。

后台提示词由 `src/xiaoba_agentos/user_rules.py` 统一加入本规则，AGY、DSH 和兼容 CLI 共用；规则不依赖 KnowLP 命中、任务上下文或历史记忆。第二大脑运行宪法由同一规则生成。任务输出有严格约束时，规则仍适用，但不要求在答案中复述。
