# 防复发草案（待用户初审）

> 本文件是仓库内草案，**不是**已发布第二大脑规则。请用户审阅后，再决定是否拷入本机 Vault 的 `70_复利规则/`。禁止写入 `release/second-brain/`（那是 v1.6.1 快照）。

## 适用

小八 AgentOS 工程改动与经验入库存证相关的重复成本。证据来自 2026-10-22～2026-11-21 仓库提交与 PR，不是生产监控。

## 四条可复用结论

1. **先认权威层**：用户原话 → 运行根 → 拓扑 → 候选代码 → 活动监看树 → 冻结快照。改错层等于白干。  
2. **存活不是身份**：PID 存活、退出码 0、空探测结果都不能单独决定“是它”或“没有它”。  
3. **新门默认最小范围**：评分/验收/台账新前置条件必须写清不适用时走旧路径；默认不要失败。  
4. **对齐类 FAIL 先本地化**：文档↔代码矛盾不要消耗审查轮次；仓库目前没有产品测试 CI，轮次预算很贵。

## 明确不自动退役的规则

正式经验不因失败次数自动淘汰；复用改动与长期未用走用户终审——这是有意设计，不在“简化”范围内砍掉。
