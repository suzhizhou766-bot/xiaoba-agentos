# 模型链路与认证

现行后台链路：

```text
agy_review → AGY CLI（临时目录、plan+sandbox）→ Antigravity本地登录 → 上游
dsh_review → DeepSeek Harness CLI → Desktop 保存的模型与上游配置 → 上游
```

两个后台都要成功，互不代替。凭据由客户端持有，不进入知识库；不声称对子CLI所有内部工具都有逐步审计。

后台AGY/DSH的就绪只由真实探针决定，不以桌面宿主是否在线代替；不得改桌面登录材料或桌面自选的模型来修复后台任务。
