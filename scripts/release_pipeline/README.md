# 发版编排工具（75P / 75Q / 75R）

本目录收拢原散落在工作区的发版编排与包外同步恢复工具，纳入主仓版本管理（不进入不可变运行包）：
- `driver75p/`：隔离现场准备、冻结、节点就绪与派审驱动（75P）。
- `stage75q/`：正式包构建、门禁校验与复制现场演练（75Q）。
- `stage75r/`：包外监看部署、旧监管交接与断点恢复工具（75R，已对齐 v1.6.17/v1.6.18 最新版）。

所有监看源码路径已统一收敛至主仓顶层 `monitor/`（消除旧 `architecture-package-20261027/shared/工具/小八监看` 硬编码）。
